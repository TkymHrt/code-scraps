## 3. 3枚の図の定義と、0パスの手動設定

### 3.1 記号と単位

区間長を `L`、抽出・平滑化後の側辺長を `l` とすると、超過率は次です。今回の入力区間長は `L = 100mm` です。

```text
超過率                 E_p = (l_p / L - 1) × 100          [%]
初回差                ΔE_p = E_p - E_0                  [ポイント]
左右差                 D_p = E_DR,p - E_OP,p             [ポイント]
```

`p` はパス番号です。DRとOP、実験回、区間を分けて計算します。「ポイント」はパーセントポイントの略です。

100mmの軸方向区間に対して、側辺をたどった長さが103mmなら超過率は3%です。これは材料の伸びひずみ3%や、クラック面積率3%ではありません。

基準区間長は、試料の長手軸に直角な2本の断面の軸方向間隔です。単に写真の縦方向へ100mmを取ることや、側辺の両端を結ぶ直線距離とは区別します。

### 3.2 今回、初回差図と超過率図が同じ動きをする理由

今回の0パスは、両側とも `l_0 = L = 100mm` と置いているので、`E_0 = 0%` です。そのため、各区間・各側で次が成り立ちます。

```text
ΔE_p = E_p - 0 = E_p
```

したがって、**`change_from_initial.png` と `excess.png` は、今回の設定では同じ数値を別の説明で表示します。** 2枚で似た傾向が出たことを、独立した2つの検証結果とは数えません。

これは後続パスで観察された傾向そのものを否定するものではありません。ただし「2種類の指標で裏付けた」と説明するのではなく、超過率の1つの結果として示します。

主図は `excess.png` にし、初回差図は「今回の設定では数値が重複する補助図」として扱うと説明が簡潔になります。ファイル名を変えなくても、図題・図注で意味を明示できます。

### 3.3 「実測の初期状態」と「理想直線」は違う基準

| 基準の置き方 | 初回差が表すもの |
| --- | --- |
| 本当に測った0パスの超過率を引く | 観測した初期側辺形状に対する変化 |
| 今回のように0パスを理想直線の0%へ置き換える | 理想直線基準で見た各パスの超過率 |

例えば、本当の0パスが1%、後のパスが3%だった場合、実測初回差は2ポイントですが、理想0%基準の値は3です。今回の設定では、実験前からあった端部の凹凸を差し引いたことにはなりません。

また、手動設定した0パスの点は、観測点ではありません。表示するなら「設定した理想基準」として、実測点と区別します。0パスの全点が0で散らばらないことも、設定による結果です。0パスを含めた見た目だけから、パスに伴うばらつき増大を論証しないようにします。

発表での表現は次が適切です。

> 0パスは実測値ではなく、側辺が直線である理想状態として両側100mmを設定しました。そのため、初回差図は実質的に理想直線からの超過率を示します。実測した初期形状からの増分を示すには、0パスの実測値を用いた再評価が必要です。

元の測定記録がある場合は、理想値で上書きせず保管し、「実測値」と「表示・比較用の基準値」を分けます。今回の資料を整えるために、0パスを実測したことにして値を補う必要はありません。

## 4. 寸法検証の平均絶対誤差率4.01%をどう扱うか

### 4.1 この値から報告できること

> 補正後の画像で手動指定した2点間距離を、水平・垂直方向に配置したメジャーの距離と比較した。約20枚の画像で確認し、集計した平均絶対誤差率は4.01%だった。

これは、実画像へ補正を適用し、物理的な長さとの対応を照合した実績です。一方、絶対誤差率の平均だけでは、誤差の向き、最大値、画像内の位置差、再測定での散らばりは分かりません。

報告資料では、誤差率の計算式と平均の方法を併記します。実寸を分母とする通常の定義なら、距離の比較ごとに次です。実際の集計表とこの定義が一致するかを確認します。

```text
符号付き相対誤差 e_i [%] = (画像の距離_i - メジャーの距離_i)
                         / メジャーの距離_i × 100

絶対誤差率 a_i [%] = |e_i|

平均絶対誤差率 [%] = a_i の合計 / 距離の比較本数
```

約20枚という画像枚数と、上式の比較本数は必ずしも同じではありません。1枚で水平・垂直を1本ずつ測っていれば、距離の比較本数は画像枚数より多くなります。現時点では、これを「40点」と決めて書きません。

また、報告された「左右平均」が、左右それぞれの平均を等しく平均した値なのか、全測定をまとめた平均なのかも記録します。左右で測定数が違えば、2通りの平均は一致しない場合があります。

### 4.2 まだ主張できないこと

| 表現 | なぜ避けるか |
| --- | --- |
| 「精度は±4.01%」 | 平均絶対誤差率は、一定の確率で収まる範囲や最大誤差ではない |
| 「全点が4.01%以内」 | 平均から個別点の上限は分からない |
| 「95.99%正確」 | 100から引いて正確さを表す定義ではない |
| 「校正の再投影誤差が4.01%」 | 今回は物理寸法との誤差率。校正プログラムの再投影RMSは画像上のずれで、単位px |
| 「補正で誤差を4.01%まで改善した」 | 改善量を述べるには、同条件の補正前との比較も必要 |
| 「側辺長とクラック量も4.01%で測れる」 | 手動2点間距離の照合と、抽出輪郭の弧長・クラックの計測は別 |

測定誤差と測定不確かさは、計測学でも区別する概念です。平均的な参照値との差を、そのまま結果の保証範囲として使うことはできません。[VIM：測定誤差](https://jcgm.bipm.org/vim/en/2.16.html)、[VIM：測定不確かさ](https://jcgm.bipm.org/vim/en/2.26.html)

### 4.3 4.01%で十分かという質問への考え方

許容できるかは、何mmの寸法差、何ポイントの形状指標の差を区別したいかで変わります。4.01%という平均1つだけから、合格・不合格を決めません。

たとえば100mmを比較する場面で4%の差は4mmに相当します。ただし、これは単位を理解するための例で、「今回のすべての100mm区間に4mmの誤差がある」と確認したわけではありません。検証に使った実際の距離範囲も示します。

寸法の検証は少なくとも、水平／垂直、中央／左右などの画像内位置、符号付き誤差、最大絶対誤差へ分けると、残る偏りを説明しやすくなります。メジャーと試料面の高さ、メジャーが平らか、クリックした目盛りの対応も確認します。

### 4.4 4.01%を超過率へそのまま当てはめない

同じ輪郭と同じ断面端点を固定し、1pxあたりの長さを `s` とすると、超過率の式は次です。

```text
E = 100 × ((側辺のpx長 × s) / (区間のpx長 × s) - 1)
  = 100 × (側辺のpx長 / 区間のpx長 - 1)
```

この限定した条件では、共通の一様倍率は比の中で相殺します。したがって「絶対寸法に平均4.01%の差があるから、超過率も必ず±4.01ポイントの誤差」という換算はできません。

ただし、実際のGUIは入力した100mmを倍率で割って、何pxの区間にするかを決めます。評価間隔と平滑化幅もmm指定からpxへ変換します。倍率が違えば、実物上で測る範囲や評価する細かさも変わります。さらに、縦横の倍率差、位置によって変わる歪み、面外の反り、輪郭の抽出誤差は、上の一様倍率の相殺では解消しません。

つまり、寸法検証は必要ですが、その4.01%だけで超過率の変化の有意性や検出限界は判断できません。比較指標そのものを同一区間で測り直し、どの程度変動するかも確認します。

## 5. 超過率・初回差が右肩上がりであることの考察

### 5.1 現段階での読み方

> 今回採用した100mmの局所区間では、パスの進行に伴い、理想直線に対する側辺長の超過率が増える傾向が見られたと報告された。

同じ基準長に対して、測定した側辺をたどる長さが大きくなる傾向です。外周の凹凸、切り欠き、うねりなどが大きくなる場合と整合します。

「右肩上がりの傾向」は、全パスで必ず単調に増えたことや、統計的に有意な傾きが得られたことまでは意味しません。実際の各値を確認するまでは、増加量・変化率・相関係数・有意確率を付けません。

さらに、手動設定した0%から最初の実測点へ上がったことだけでは、圧延に伴う増加を実証したことにはなりません。**増加傾向は、実測した後続パス同士でも見られるかを確認します。** 設定した0パスを観測点として回帰や傾向評価へ混ぜると、上昇を強く見せる可能性があります。実測パスが1つしかなければ、その値を示すことはできてもパス依存の傾向は評価できません。

### 5.2 エッジクラックが増えている可能性はあるか

可能性のある説明です。外周へ開いたき裂が輪郭に切り欠きとして写り、その形を抽出・保持できていれば、輪郭に沿う距離が増える場合があります。

ただし、輪郭長だけでは「き裂の数が増えた」「1本のき裂が深くなった」「幅のあるうねりが増えた」を分けられません。外周へ開かない割れ、解像できない細い割れ、平滑化で消える形状は指標に現れにくくなります。欠損や抽出の短絡によって、損傷が進んでも輪郭が短くなる場合も考えられます。き裂量と指標の単調な対応は未検証です。

発表では、次の段階を分けます。

| 段階 | 今回の位置付け |
| --- | --- |
| 外周の形状指標にパス依存の傾向が見えた | 利用者の図の観察として報告されている |
| エッジクラックの進展と整合するかもしれない | 検証する価値のある仮説 |
| クラックの本数・深さが増えたと確認した | 拡大画像などとの照合が必要 |
| 圧延条件が原因で増えたと特定した | 材料・加工条件・独立した実験などが必要 |

圧延における端部割れには、変形・温度・応力の不均一性などが関与する研究例があります。たとえばAZ31マグネシウム合金の熱間圧延を対象に、温度・圧下条件と端部き裂を実験・解析した原著があります。ただし、今回の材質・温度などは未共有で、その機構を今回へ直接当てはめる根拠にはなりません。[Jiaら（2020）](https://www.sciencedirect.com/science/article/pii/S2238785419309998)

### 5.3 一緒に検討する別の説明

| 候補 | 指標へ影響し得る理由 | 区別する確認 |
| --- | --- | --- |
| 実際の外周の凹凸・開口したき裂 | 輪郭をたどる距離が増える場合がある | 元画像・拡大画像と計測線を重ねる |
| 長い周期のうねり・幅の局所変化 | 側辺の傾きや蛇行が増える場合がある | き裂の切り欠きと大きな波形を見分ける |
| 長手軸のずれ | 側辺に対する断面の向きが変わる | 自動軸と確認した手動軸で比べる |
| 反射・影・ブレによる抽出誤差 | 存在しない凹凸を輪郭がたどる、または短絡する | 原画像の境界と抽出線の一致を見る |
| 面外変形・基準面からの高さのずれ | 平面補正の前提と実試料面がずれる | 側面や固定物、試料の高さを確認する |
| 区間の選び方の変化 | パス間で形状の違う場所を採用している可能性 | 上・中・下の位置、再選定理由、欠測を記録する |

単に試料幅が大きくなるだけで、軸に平行な直線側辺の超過率が必ず増えるわけではありません。形状の変化が側辺の向きや凹凸へどう現れたかを見ます。

## 6. 後半パスほど点の散らばりが大きく見えること

### 6.1 「長さが不安定」より「場所による形状差」と表現する

上・中・下など異なる区間の点を見ているなら、まずは次のように説明できます。

> 後半パスでは、採用した局所区間の間で超過率の散らばりが広がるように見えた。側辺形状の変化が一様ではなく、場所による差が大きくなる可能性がある。

この所見だけで、「測定器の値がぶれる」「同じ場所が時間的に不安定」「クラックのある箇所数が増えた」とは決められません。散らばりは、局所形状の差に加え、抽出・軸・区間設定の違いでも生じます。

また、大きな値の区間が1つ増えただけでも散らばりは広がります。「不安定な場所の数が増えた」と言うには、位置ごとの画像照合や、事前に定義した判定基準に基づく区間数の確認が必要です。

**0パスは全点を0に設定しているため、0パスの散らばり0は測定結果ではありません。** ばらつきの進行を考えるときは、実測した後続パス同士で比較します。

### 6.2 どのばらつきを見たかを分ける

| 比較するもの | 主に確かめたいこと |
| --- | --- |
| 同じパス・同じ画像の上／中／下 | 場所による形状差と、各区間の計測誤差 |
| 同じ画像・同じ区間を指定し直して再測定 | 手動指定・抽出・軸の再現性 |
| 同じ条件での別フレーム・撮り直し | 位置・姿勢・ブレ・照明などを含む差 |
| 独立した試料・独立した圧延実験 | 実験結果の再現性 |

測定過程の短期的なばらつきと、環境や操作条件を含むばらつきを分けて調べる考え方は、NISTの測定過程評価でも扱われています。今回の上・中・下の散らばりを、同一区間を測り直したときの精密さと同じものにはしません。[NIST：Variability](https://www.itl.nist.gov/div898/handbook/mpc/section1/mpc114.htm)

### 6.3 数値として確認するなら

同じパス・同じ側の区間値を集め、まず全点と区間数 `n` を示します。SDを求める場合は区間間の標本SDとして、各パス・各側で別々に計算します。

```text
平均 E_bar = 区間の超過率の合計 / n

標本SD = sqrt( 各区間の (E_i - E_bar)^2 の合計 / (n - 1) )
```

`n = 1` なら標本SDは求められません。0とは置きません。上・中・下の3区間しかない場合、SDは計算できても少数の区間値に左右される記述的な指標なので、その値だけで分布や有意差を確定しません。

区間数がパスごとに異なれば、最大値と最小値の開きの比較も単純ではありません。平均が0付近の超過率を変動係数 `SD / 平均` で評価すると不安定になるため、最初はポイント単位の散らばりを示す方が説明しやすくなります。

### 6.4 標準偏差を図から外したことの説明

主図の視認性のために、SDの誤差棒を表示しない選択はできます。ただし、ばらつきを結果から消したことにはしません。

> 複数の線と誤差棒が重なって傾向を読み取りにくかったため、主図では個々の区間の値を中心に示しました。区間間の散らばり自体も検討対象とし、区間数と数値表、必要に応じた補助図で確認します。

この説明を使うなら、個別点が残っていることを確認し、補助表を実際に用意します。未集計なら「SDの増加を確認した」とは言わず、「個別点の散らばりが広がる印象があった」とします。

誤差棒を削除して見やすくなっても、測定の不確かさや区間間の差そのものが小さくなったわけではありません。

## 7. DR−OP差が右肩下がりで、OPが大きいこと

### 7.1 ゼロとの位置と、傾きを分ける

左右差は `D = E_DR - E_OP` です。

| Dの状態 | 意味 |
| --- | --- |
| 正 | DRの超過率が大きい |
| 0 | 両側の超過率が等しい |
| 負 | OPの超過率が大きい |
| パスとともに減少 | OPに対するDRの相対的な優位が小さくなる、またはOP優位が大きくなる方向 |

右肩下がりだけでOPが大きいとは限りません。例えば `+3 → +1` なら、差は減っていてもDRの方が大きいままです。`−1 → −3` なら、OP側が大きく、その差が拡大しています。

利用者からは「OP側が大きい」とも報告されています。発表前には、実際の図が負側にあるパスと、途中で符号が変わるかを確認し、「全パスでOP優位」と必要以上に広げないようにします。

今回の0パスは両側を理想長に設定したため、`D_0 = 0` も設定による値です。設定0から負の実測値へ下がったことだけでは、初期の実物が左右対称だったことや、圧延で左右差が発達したことを実証しません。左右差の下降傾向も、実測した後続パス同士で確認します。

### 7.2 超過率の増加と合わせて読む

同じ区間・同じ基準の2時点を比較すると、左右差の変化は次です。

```text
D_後 - D_前 = (E_DR,後 - E_DR,前) - (E_OP,後 - E_OP,前)
```

これが負なら、OP側の増分がDR側の増分より大きい関係です。ただし、片側が減った場合でも左右差は下がり得るので、必ずDR・OPそれぞれの元の図も示します。

同じ区間構成で両側の超過率が増え、かつDが負側へ下がることを実際の値で確認できた場合は、次のように説明できます。

> 両側で側辺長の超過率が増える傾向があり、とくにOP側の増加が相対的に大きい可能性がある。

### 7.3 左右差の原因の候補

加工条件・材料の初期端部状態などの物理的な左右差と、照明・残る歪み・軸・輪郭抽出などの計測上の左右差を分けます。今ある図だけでは、圧延機の片側に問題がある、OP側の温度が低い、といった原因は決められません。

手元のコードは画像左をDR、右をOPとして扱います。実物の側との対応、撮影時の回転・裏返し・反転の有無も確認します。手元のコードに、圧延の進行方向から左右名称を自動的に入れ替える処理はありません。外部端末での運用は撮影・処理記録で確認します。

平均絶対誤差率4.01%は符号と左右の内訳を隠すため、この値だけで「左右差は補正済み」とは言えません。水平・垂直方向の確認に加え、画像の左右位置で寸法差や抽出の偏りがないかを見ると、OP優位の解釈を支えやすくなります。

## 8. なぜ全長を測らず、100mmの局所区間なのか

### 8.1 実際の出発点を隠さず説明する

今回の理由は、全長を対象にしたときに、抽出輪郭が試料内部へ入り込むなどの誤抽出が生じたことです。上・中・下の区間は、そのような誤抽出と判断した場所を避け、元画像との対応を確認して選定しています。

この事実を、後から別の理由だけに置き換える必要はありません。方法としての狙いと限界をつなげる方が、質問にも答えやすくなります。

> 全長を対象にすると、一部の誤抽出が形状指標に混ざる問題がありました。そこで今回は、元画像と輪郭の対応を確認できる100mmの局所区間を上・中・下で選び、同じ評価長で側辺形状を比較する方法を採りました。クラックの有無で選んだのではなく、元画像と一致しないと判断した抽出箇所を避けています。ただし、全長を代表する評価や、全長での抽出問題の解決までは達成していません。

### 8.2 局所区間を使う、方法上の意義

| 意義 | 説明できること | 限界 |
| --- | --- | --- |
| 評価範囲を揃える | パス間で100mmという同じ軸方向長さを比較する | 正しい倍率と同じ区間選択規則が前提 |
| 局所差を残す | 上・中・下の形状差を、全体の1値へまとめず見られる | 3位置が全体を代表する保証はない |
| 輪郭を確認する範囲を限定する | 数値と原画像・計測線の対応を見直しやすい | 短くしても誤抽出がなくなるわけではない |
| 影響の場所を調べる | 大きい値が出た区間を拡大画像と照合しやすい | 同じ材料部分をパス間で追跡したわけではない |

「単位長さ当たりにしたいから」だけでは、局所区間を選んだ理由としては十分ではありません。全長でも、全長の基準長で割れば正規化できるためです。今回は、**局所形状を同じ長さで比較する目的と、全長で生じた抽出上の制約**を一緒に述べます。

全体を1値で表すと局所的な大きい変化が平均化されることは、局所評価の利点として説明できます。ただし、それを今回の実際の初期動機だったことに書き換えません。

### 8.3 全長評価も意味がある

全長を正しく抽出でき、各区間の側辺長と基準長を同じ定義で足せるなら、全体の超過率は局所の超過率を区間長で重み付けした平均になります。等長区間なら、その区間値の平均です。

```text
E_全体 = Σ(L_i × E_i) / ΣL_i
```

これは側辺長が区間間で重複なく加算できる場合の関係です。実際には、軸を局所ごとに推定することや区間端の平滑化処理により、局所値をつないだ結果と一括計測値が完全一致するとは限りません。

全長指標は全体の平均状態、局所指標は場所による違いを知るのに役立ちます。優劣だけの問題ではありません。今回、未計測の隙間や除外箇所があれば、上・中・下の平均を「全長の平均」とは呼びません。

### 8.4 区間選択の偏りへの対応

今回避けたのは、元画像と合わないと判断した誤抽出箇所です。ただし目視で選ぶ以上、境界が読みやすい場所へ偏る可能性は残ります。損傷の大きい場所ほど抽出しにくい場合、実際の損傷量を低く見積もる方向にも働き得ます。

次の区別を、記録と発表で維持します。

- **真の凹凸や開口したき裂**：画像にも存在する形状。値が大きい、内向きにへこんでいるという理由では除外しない。
- **誤抽出**：画像の実境界と計測線が合わない。指定を直して再処理し、直せなければ理由付きの未計測とする。
- **判別できない場所**：真の形状か誤抽出か決めつけず、要確認として残す。

継続して評価する場合は、例えば試料端からの位置・上中下の取り方・区間の重なり・再選定の範囲を、値を見る前に決めておくことが有効です。今回、事前に規則を固定していなかった場合は「目視で選んだ予備評価」と説明し、過去に固定規則があったことにはしません。

採れなかった区間を超過率0として埋めず、失敗・除外箇所の画像と理由を残します。各パスの採用数だけでなく、候補数と未計測数も分かると、後半パスで測りやすい場所だけが残っていないかを検討できます。

| 5 | 同じ画像・同じ区間を指定し直して再測定 | 手動指定・抽出・軸による結果の再現性 | 区間間の差と測定のぶれを分ける |
| 6 | 実測パスについて、個別点・平均・SDなどを確認 | 散らばり増大という印象が数値でも見られるか | 「印象」から「記述統計による確認」へ進める |
| 7 | 代表区間で評価間隔・平滑化幅・軸の設定を変えて比較 | 結論が特定設定へ強く依存するか | 指標が捉える形状の細かさを説明する |

再測定では、同じ点を自動計算し直すだけでなく、多角形・中心・軸などの指定をやり直すことで、実際の操作による差を見ます。一方、撮り直しまで含めた差は別に扱います。少数回の確認から、一般的な精度保証が得られたとはしません。

クラックとの照合では、定規の直線距離だけでなく、同じ評価区間の外周を人が確認した結果と比較することが役立ちます。手動輪郭も完全な正解ではないので、複数の確認者や拡大画像を使い、曖昧な箇所を残します。

画像によるき裂先端の計測を扱った研究でも、手動計測や別の測定法との比較が行われています。ただし、その研究はSEM画像による微小破壊試験であり、今回の圧延外周指標を検証したものではありません。ここでは、物理的なき裂との対応を別途照合する必要性を考える参考とします。[Schmuckら（2022）](https://link.springer.com/article/10.1557/s43578-022-00681-4)

| パス0からの実測変化を示す | 0パスを理想直線の0%に設定した基準で示す |
| 2種類の図で増加を確認した | 今回は初回差と超過率が数値的に同じになる |
| OP側のクラックが多い | OP側の超過率が大きい傾向が報告された。クラック量との対応は未確認 |
| 全長より局所計測の方が正確 | 全長での誤抽出を避け、確認可能な一定長区間で局所比較した |
| SDがぶれるので消した | 主図の視認性のため誤差棒を省いた。散らばりは個別値と補助資料で確認する |
| 同じ100mmなので同じ材料を比較している | 各パスで同じ長さの区間を比較した。同じ材料部分の追跡は保証していない |
