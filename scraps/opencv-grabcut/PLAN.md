# 現在の実装方針

2026-10-15更新。ルート・題材のREADMEと、`submissions/AGENTS.md` の方針を守る。
初心者が上から処理を追える、独立した単発スクリプトを順番に使う。
自作共通モジュール・複数工程をまとめる実行コード・設定管理の枠組みは作らない。

## 現行の範囲

1. 板生成：ChArUco板だけをPNGへ保存。
2. カメラ校正：写真ごとの読取確認PNGを保存し、魚眼モデルの係数をコピペ用に表示。
3. 補正画像出力：指定フォルダを魚眼係数と板で一括補正し、写真内の向きを保った計測用の補正PNGだけを保存。
4. 計測GUI：補正画像で初期指定・材料区間を選び、左右側辺長のCSV・確認画像を保存。
5. 長さ分析GUI：複数撮影のCSVと初期区間長・初期厚さ・各回の厚さを使って比較。

2026-10-15、5の別案として独立した `submissions/length_analysis_gui.py` を追加。
同じCSVから圧延方向の区間長を計算し、伸び・左右側辺形状・直前パスからの割合の変化を分析する。
数値表と推移・前回変化のグラフを一画面に表示し、分析CSV・PNGを保存する。
既存の5本は維持し、幅・局所形状・誤差評価は追加しない。

同日、最小比較として `submissions/length_comparison_simple_gui.py` を追加。
初期区間長・初期厚さと各撮影の厚さから求めた理想片側長と、CSVの左右側辺長を数値表・1枚の推移グラフで比較する。
左右の理想差をmmで求め、比較CSV・PNGを保存する。

同日、GUIなしの `submissions/length_comparison_simple.py` を追加。
コード冒頭で初期区間長・初期厚さ・CSVと各撮影の厚さを指定し、左・右・理想片側長の3本線をPNGだけへ保存する。
指定順を撮影順とし、ファイル選択・ウィンドウ表示・設定ファイル・追加の換算は使わない。

画像補正と計測GUIの `MM_PER_PX` を同じ固定値にする。
補正PNGから計測GUIで直接mm長さを求めるため、画像ごとの換算CSVと後処理のCSV換算は使わない。
カメラ係数や倍率の対応、画像と出力名の管理は運用で行う。
カメラ校正の読取確認PNGにはマーカー枠・角のID・読取点数・OK/NGを重ねる。NG画像も保存してから停止する。
画像補正の確認PNGは作らない。魚眼補正後の板の横軸の向きを残し、板基準に写真全体を回転させない。
計測GUIでy方向の区間を選ぶため、試料の長手は撮影時に画像の縦へ揃える。
途中のエラーでは止め、入力を直して再実行する。出力の退避と古い結果との対応確認は運用で行う。
魚眼レンズを前提とし、OpenCV 5の魚眼モデルに固定する。歪み係数は `k1,k2,k3,k4` の4個。
通常モデルの既存係数は流用せず、同じ画角・モード・解像度の写真から校正し直す。

比較するのは、印などで確認した対応する同じ材料区間。
幅一定・体積一定を仮定し、理想片側長を初期区間長×初期厚さ÷各回の厚さで求める。
CSVを追加順で比較し、各回の厚さは行へ直接入力する。並べ替え・撮影名編集・フルパス欄は置かない。実寸・理想差・差率・前回差とグラフを同じ画面で確認して保存する。各画像のy座標を一致させる必要はない。

計測GUIの抽出・側辺長の定義は従来03を引き継ぐ。
GrabCut、最大の外側輪郭、各行の最左・最右の連結を使い、上下辺を長さへ含めない。
区間の途中に試料がない場合は計測を止める。

## 配置

実践用5本は `submissions/`。旧提出版と変更前のコピーは `sandbox/previous_submissions/`。
題材直下の旧実践コード7本は `sandbox/previous_scripts/`。
幅・凹み候補・エッジ表示など、今回の流れの外にある機能は退避する。
自動試験・操作検証は `tests/`。現行の標準出力先は `submissions/output/`、補正PNGはその中の `rectified/`。過去の結果は保管する。

旧版の試験は退避先を参照して維持する。現行の画像・CSV受け渡しを別途検証する。
生成画像と合成カメラの結果を、本番画像や実カメラの精度として扱わない。

以前の計画と完了記録は [退避したPLAN](sandbox/previous_submissions/PLAN.md)、
現在の操作手順は [submissions/README.md](submissions/README.md) に残す。
