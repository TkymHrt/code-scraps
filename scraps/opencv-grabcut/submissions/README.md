# 提出用

段階ごとの成果を、短く読めるスクリプトで提出する場所です。
既存コードは参考として残し、提出版は必要な処理だけで1本ずつ作ります。
ここでは、再現性・設定調整・入力の選定を運用で扱う方針を優先します。
既存の工程表にある記録項目を、提出コードの必須機能にはしません。

## 初期指定と抽出結果

GrabCutには、前景・背景とそれぞれの候補を示す**初期マスク**を渡せます。
これは「どこを試料・背景として扱うか」の手がかりです。
確実な前景・背景の指定は固定され、候補部分は画像に基づいて判定されます。
判定後の前景を白、背景を黒にしたものが**抽出結果の2値マスク**です。
入力する初期指定と、出力する抽出結果を分けて確認します。
仕様は [OpenCVのGrabCut解説](https://docs.opencv.org/4.x/d8/d83/tutorial_py_grabcut.html) を参照してください。

この提出版では、矩形の設定を初期マスクへ書き込み、`GC_INIT_WITH_MASK` で渡します。
GrabCutは画素ごとに指定できるため、初期マスクは矩形に限りませんが、今回は矩形だけで作ります。
「人の指定あり」は人が画像ごとに矩形を調整すること、
「画像ごとの追加指定なし」は共通ルールなどで初期マスクを作ることです。
どちらも初期マスクは必要です。現在の提出版は人の指定ありです。

## コードの形

- 1つの成果につき1スクリプト。設定・読み込み・処理・保存を上から読めるようにする。
- 入力・保存先・調整する数値は冒頭に置き、必要なときに人が編集する。
- 小さな関数と短い重複は許容し、自作の共通モジュールには依存させない。
- 実行条件JSON、設定管理、実行履歴、自動バックアップや復旧処理は足さない。
- 入力が読めない、計測が成立しない場合など、誤った数値を出さないためのチェックだけ残す。

結果画像と、定量評価そのものに必要なCSVを保存します。
撮影条件を揃える、設定を合わせる、出力を見て確認する、必要な結果を残すことは人が行います。
同じ保存先への上書きは、実行前に確認します。

## 01のGUI版で初期指定を作る

[01_initial_regions_gui.py](01_initial_regions_gui.py) は、01の別バージョンです。
画像上で矩形を描いて初期マスクを作り、元画像へ色を重ねた確認画像を保存します。
起動時は矩形を置かず、手動で指定します。GrabCutによる抽出は02が担当します。
題材の `opencv-grabcut` フォルダから起動します。OpenCV・NumPyに加えてPythonのTkinterを使います。
「画像を読み込む」からOS標準のファイル選択画面を開き、保存先は保存時に指定します。

```powershell
uv run submissions/01_initial_regions_gui.py
```

この環境で `uv` が呼び出せない場合は、同じフォルダから `.\.venv\Scripts\python.exe submissions/01_initial_regions_gui.py` で起動できます。

1. 「画像を読み込む」を押して元画像を選びます。キャンセルすると現在の画面を保ちます。
   別の画像を読み込むと矩形を消し、空の状態から指定します。
2. 前景候補（橙）・確実な背景（青）・確実な前景（緑）を選び、初期指定の表示上でドラッグします。
   前景候補は1つで、描き直すと置き換わります。背景・前景は複数追加できます。
3. 矩形一覧から選ぶと黄色の枠で位置を確認でき、「選択した矩形を削除」で消せます。
   「矩形をすべて削除」で空の状態に戻せます。
4. 「元画像」と「初期指定」を切り替えて照合し、「確認画像を保存」を押します。
   保存先とファイル名を選び、PNGで保存します。保存のキャンセルではファイルを作りません。

表示だけをウィンドウに合わせて縮小し、指定と保存は元の解像度で行います。
初期マスクのラベル・優先順位・重ねる色は01と同じです。
余白と操作部の間隔は4pxの倍数に揃えています。
矩形の種類には16px角の色見本を付け、重ね表示と同じパレットから色を取り出します。

後段の02・03・05〜08でも同じ指定を使うときは、「初期指定の設定をコピー」を押します。
`CANDIDATE_RECT`・`BACKGROUND_RECTS`・`FOREGROUND_RECTS` の3項目をコピーします。
GUIを開いたまま、使う提出版の同名の3項目を置き換えてください。

未読込での保存、読めない画像、保存先の間違い、前景候補なしのコピーは、画面下部に理由を表示して操作を中止します。
通常スクリプトは、設定や読み込み・保存に問題があれば例外で止め、修正して再実行します。
ファイル操作自体が出す例外はそのまま使い、共通のエラー管理や自動復旧は追加しません。

## GUIで計測パラメータを決める

題材の `opencv-grabcut` フォルダから起動します。OpenCV・NumPy・Tkinterを使い、1本で動きます。

```powershell
uv run submissions/measurement_settings_gui.py
```

手元の生成画像で試すには、「スクリプトから設定を読む」で `08_candidate_sizes.py` を選び、「計算して確認」を押します。
入力画像・初期指定・計測範囲・正常部分・候補条件が入り、これまでと同じ左2・右7の候補を確認できます。
設定値はPythonのリテラルとして読み取ります。

新しい画像では、01のGUIで初期指定を作ってコピーし、このGUIの「画像を読み込む」で同じ画像を選び、
「01の初期指定を貼り付け」で矩形の3設定を渡します。「初期指定」表示で対応を確認できます。
画像を読み直すと、画像ごとの初期指定・正常部分を消し、計測範囲を画像全体に戻します。

1. 「計測範囲（黄）」を選んで画像上を上下にドラッグします。逆向きでも指定できます。
   開始y・終了yで微調整でき、「画像全体を計測範囲にする」で全行に戻せます。
2. 基準線や候補を使う場合は「左の正常部分（緑）」「右の正常部分（水色）」で、それぞれ正常とみなす区間をドラッグします。
   横位置は使わず、選んだyの左右端を使います。複数区間を追加でき、一覧から選んだ区間を太い枠で確認し、削除できます。
3. 「計算・候補条件」タブで、反復回数・乱数シード・内向き偏差・最小連続行数を入力します。
4. 「用途・コピー先」を選び、「計算して確認」を押します。
   「計測（03・05）」は正常部分を指定せず確認できます。「基準線（06）」は正常部分も使い、「候補（07・08）」は候補条件も使います。
5. 「元画像＋範囲」「初期指定」「計算結果」を切り替えて照合します。
   側辺長・幅、候補数・最大偏差・影響範囲も画面に表示します。候補番号は縮小表示でも読める大きさに保ちます。
6. 「設定をコピー」を押し、対象スクリプト冒頭の同名の設定を置き換えます。必要なら「確認画像を保存」で元解像度のPNGも残せます。

コピーする値は、計測用が入力・矩形・抽出条件・計測範囲の8項目、基準線用が正常部分を加えた10項目、候補用がしきい値・行数を加えた12項目です。
入力パスは絶対パス、矩形は丸めない値、yは元画像の整数座標でコピーします。
変更後の結果は「未計算」に戻します。範囲・正常部分・候補条件だけの調整では抽出マスクを使い直し、
画像・初期指定・反復回数・乱数シードを変えた場合にGrabCutを再実行します。
未指定・範囲外・正常部分の重複・候補条件の誤りは画面下に理由を表示します。入力画像と同じ保存先は拒否します。

## 画像ごとに校正してmm換算するGUI

[length_calibration_gui.py](length_calibration_gui.py) は、元画像の既知寸法で03の長さをmmへ換算するツールです。
校正済みの長さCSVを1画像につき1ファイルで保存します。厚さ・理想スラブ・撮影順は設定しません。

題材の `opencv-grabcut` フォルダから起動します。OpenCV・NumPy・Tkinterを使い、1本で動きます。

```powershell
uv run submissions/length_calibration_gui.py
```

1. 「03の長さCSV」の「選ぶ」で、計測済みの `03_side_lengths.csv` を選びます。
2. 「計測した元画像」の「選ぶ」で、**そのCSVを03で計測した元画像**を選びます。
   CSV自体に元画像の名前はないため、計測時の入力と照合して選んでください。
3. 「既知寸法から校正」を押し、定規などの既知寸法の両端をクリックします。
   「基準物の実寸 (mm)」へ長さを入力すると、距離pxとmm/pxが表示されます。
   「全体」は画像全体を表示し、「100%」は元解像度で表示します。スクロールバーで基準物の位置へ移動できます。
   2点指定後の次のクリックは新しい1点目になります。「点を消す」でもやり直せます。
4. 「この校正を使う」で、左・右・左右合計のpx値とmm値を確認します。
5. 「校正済みCSVを保存」で保存先を選びます。既定名は `calibrated_lengths.csv` です。
   撮影ごとのフォルダに保存するか、撮影名をファイル名に付けてください。
6. 次の画像も1〜5を繰り返します。別の長さCSVに切り替えると元画像・校正を解除するので、画像ごとに選び直します。

```text
mm/px = 基準物の既知の長さmm / 画像上の両端間距離px
実寸側辺長mm = 03の側辺長px × その画像のmm/px
```

保存CSVはUTF-8 BOM付きで、1画像につき1行です。長さと校正根拠を同じファイルに残します。

- `input_csv,image_path`：元の03のCSVと元画像の絶対パス。
- `reference_mm,reference_px,mm_per_px`：既知寸法、画像上の距離、換算値。
- `reference_x1,reference_y1,reference_x2,reference_y2,image_width,image_height`：元画像のpx座標と画像サイズ。
- `start_y,end_y`：03の計測範囲。
- `left_px,left_mm,right_px,right_mm,total_px,total_mm`：左・右・左右合計の測定値と実寸。

数値は最大12桁の有効数字で保存します。保存時にも03のCSVを読み直します。
画像の高さを超える計測範囲、不正な長さ・基準寸法・基準点では保存できません。
ファイル選択や校正のキャンセルでは現在の結果を保ち、元CSV・元画像への上書きは拒否します。

各画像には試料と同じ計測面の高さに定規などを置き、カメラを計測面に正対させます。
校正は画像内で一定の倍率を仮定した1つのmm/pxです。撮影条件は [CAPTURE.md](../CAPTURE.md) を参照してください。
手元の生成画像には実寸の根拠がないため、検証で使う寸法は仮の条件です。

## 撮影ごとの長さを比較するGUI

[length_comparison_gui.py](length_comparison_gui.py) は、**校正済みのmm長さ**を、
幅一定・体積一定の理想スラブと比較するツールです。画像表示・基準点の指定・pxからmmへの換算は校正GUIが担当します。
各CSVには、印などで対応を確認した**同じ材料区間**の計測値を使います。

題材の `opencv-grabcut` フォルダから起動します。Tkinter・Matplotlibを使い、1本で動きます。

```powershell
uv run submissions/length_comparison_gui.py
```

1. 「初期区間長 (mm)」「初期厚さ (mm)」に、対応区間の圧延前の値を入れます。
2. 「CSVを追加」で各撮影の**校正済み長さCSV**をまとめて選びます。03のpx CSVは直接読み込みません。
   「上へ」「下へ」で撮影順に並べます。後から追加でき、Ctrl・Shiftで複数行を選んで削除できます。
   同じCSVは重複追加しません。
3. 行を選んで、撮影名と「撮影時の厚さ (mm)」を入れ、「撮影名・厚さを適用」を押します。
4. 「比較する」で結果を表示します。1画像から比較でき、複数画像も同じ手順で扱えます。
5. 「推移グラフを表示」で実寸と理想長、理想との差率、前回からの実寸変化を確認します。
   「比較CSVを保存」「推移グラフを保存」でCSV・PNGを保存します。

```text
伸び倍率 = 初期厚さ / 各回の厚さ
理想区間長 = 初期区間長 × 伸び倍率
```

幅方向の変化は理想モデルに入れません。正常な直線状の区間の理想長は左右それぞれに `理想区間長`、
左右合計にはその2倍を使います。実測側辺長は03の折れ線に沿った長さで、端の凹凸を含めます。

| 結果タブ | 読むもの |
| --- | --- |
| 実寸 (mm) | 理想片側長、実測の左・右・左右合計 |
| 理想との差 (mm) | 実寸 − その撮影の理想長。左右合計の理想長は理想片側長の2倍 |
| 理想との差率 (%) | 理想との差 ÷ 理想長 × 100 |
| 前回との差 (mm) | 各撮影の実寸 − 一覧の直前の撮影の実寸 |

理想との差・差率は、厚さから計算した圧延方向の伸びを考慮した指標です。
前回差には通常の伸びも含まれます。最初の撮影の前回差は表で「—」、CSVで空欄となり、グラフに点を置きません。
理想との差だけでクラックの有無や個数は確定しません。端線と候補を画像で照合する工程は従来どおり行います。

比較時には校正済みCSVを読み直し、保存済みのmm値を使います。元画像・03のCSVを開いたり、校正点から倍率を再計算したりしません。
元画像・03のCSVが手元になくても比較できます。初期条件や厚さを変更する際に校正し直す必要もありません。
画像間の開始・終了yは揃えず、各画像の対応する材料区間を使います。

初期条件・厚さ・名前・撮影順・一覧を変更すると、結果を消してグラフウィンドウを閉じます。
選択・保存のキャンセルと重複だけの追加では現在の結果を保ちます。
校正済みCSVの空欄・不正値、px値とmm値の不整合、左右合計の不整合は拒否します。
比較対象の校正済みCSV、元の03のCSV、校正画像への上書きも拒否します。

保存CSVは撮影ごとに1行で、一覧と同じ順序です。

- `sample_id,calibrated_csv`：撮影名と入力した校正済みCSV。
- 校正済みCSVの全項目：元の03のCSV・画像・校正根拠・計測範囲・px/mm値。
- `initial_length_mm,initial_thickness_mm,thickness_mm,elongation,ideal_length_mm`：初期区間と厚さ、伸び倍率、理想片側長。
- 左・右・左右合計ごとの `delta_*_mm,delta_*_pct,previous_delta_*_mm` と `previous_id`：理想差・差率・前回差。

CSVはUTF-8 BOM付きで、数値は最大12桁の有効数字を残します。
04のpx比較と09の候補比較の設定には、次の比較設定GUIを使えます。

## GUIで比較の入力を選ぶ

```powershell
uv run submissions/comparison_settings_gui.py
```

1. 「比較の種類」で「長さ（04）」または「候補（09）」を選びます。

## 計測範囲を指定する

試料全体を写して撮影し、元画像を残したまま03の `START_Y` と `END_Y` を指定します。
GrabCutは画像全体で実行し、その後に指定した範囲だけから左右端と長さを求めます。
画像のトリミングや座標の付け直しは行いません。

```python
START_Y = 80
END_Y = 1000
```

元画像のy=80〜1000を両端を含めて計測する例です。比較する各画像で同じ範囲を指定してください。
画像内で `0 <= START_Y <= END_Y < 画像の高さ` になるよう指定します。
既定の `START_Y = 0`・`END_Y = None` は画像全体です。`None` は画像の最後の行を意味します。
上下端面が斜め・曲線・不規則でも、端面が入らない位置を人が画像で選びます。
この指定は、GrabCutの前景・背景の指定とは別の設定です。

03の結果画像は元画像と同じ解像度で、次の表示を重ねます。

| 表示 | 意味 |
| --- | --- |
| 灰色で薄くした上下部分 | 計測対象から除いた範囲。GrabCutの抽出自体はこの部分も行っている |
| 黄色の水平線 | 指定した計測開始・終了の行 |
| 赤い線 | 計測対象の左右端。03の長さに使った点列 |

成果は「指定範囲内の左右側辺長」として扱います。除外した上下端付近の欠陥は評価に含めません。
比較するときは計測範囲と撮影条件を確認し、異なる範囲の長さをそのまま比較しないでください。

## 左右端の確認画像

03は縦向きの試料を想定し、指定範囲の中で試料がある行を上から順に調べます。
各行の最も左・右にある画素を、元画像に赤い線で重ねます。上下辺は結びません。
原点は画像の左上で、xは右向き、yは下向き、どちらも0から始まる画素座標です。
試料がない行は点列に含めません。座標は縮小せず、元画像の解像度で取得します。

03の保存先は `OUTPUT_IMAGE_PATH` と `OUTPUT_CSV_PATH` で設定します。
赤線と元画像の見える端が対応しているかを確認してください。
最大の外側輪郭が試料とは限らないため、反射や背景を選んでいないかも確認します。
この段階で取得するのは行ごとの最外側の端です。内部の割れや、折り返した裂け目の全経路は表しません。

## 左右側辺の長さCSV

03は各行の左端・右端を上から順に結び、隣り合う点の距離 `sqrt(dx**2 + dy**2)` を足します。
左側・右側を別々に測り、上端・下端を横につなぐ長さは含めません。
点を間引かず、凹凸による横方向の変化も距離に含めます。

座標は画素中心なので、y=20〜140の121行の直線は120pxです。
切欠きで隣の行とのx差が大きくなる場合も、その2点を直線で結んだ距離を使います。
画素の外周をたどった長さや、折り返した裂け目の全経路の長さとは異なります。
計測範囲に上下の端面が入ると、各行の最外側の点が端面をたどり、その一部も長さに入ることがあります。
側辺だけを評価するには、`START_Y` と `END_Y` で上下端面を除く範囲を指定してください。
この段階の単位はpxで、実寸のmm換算やクラックの大きさの判定は含めません。

```csv
edge,length_px,start_y,end_y
left,120.00,20,140
right,120.00,20,140
total,240.00,20,140
```

CSVの `start_y`・`end_y` は指定した計測範囲です。上の例はy=20〜140を指定した直線の結果です。
保存先は03の `OUTPUT_IMAGE_PATH` と `OUTPUT_CSV_PATH` で指定します。
左・右・合計を小数第2位まで保存し、計測範囲とともにターミナルにも表示します。
合計は丸める前の左右の値から計算するため、CSV上の左右を足した値と0.01pxずれることがあります。
03の確認画像で範囲と端の対応を確認してから、数値を使ってください。
範囲が画像外・逆順、範囲内に試料がない場合は保存せず停止します。
03は試料が1行だけの場合も、長さの計測が成立しないため保存せず停止します。

## 幅・正常端の基準・凹み候補

05〜08は現在の生成画像を入力とし、y=80〜1000を仮の評価範囲にしています。
03の既定値は全画像なので、同じ範囲で比較するときは03の `START_Y`・`END_Y` も揃えます。

```powershell
uv run submissions/05_widths.py
uv run submissions/06_reference_edges.py
uv run submissions/07_notch_candidates.py
uv run submissions/08_candidate_sizes.py
```

05の幅は `right_x - left_x` で、画素中心間の距離です。41画素を含む直線の幅は40pxです。
CSVは `y,left_x,right_x,width_px` で、指定した範囲の全行を保存します。
試料がない行は空欄にし、グラフにも切れ目を入れます。試料がないことを幅0pxとは扱いません。
最小・平均・最大の幅は、計測できた行だけから計算してターミナルへ表示します。

06〜08では、正常端とみなす部分を元画像のy座標で左右別に選びます。
開始・終了の両端を含め、計測範囲内に2行以上、重ならない範囲を指定します。
現在の値は生成画像の比較的変動が小さい区間から仮に選びました。正常端の正解ではありません。

```python
LEFT_REFERENCE_RANGES = ((180, 200), (800, 825))
RIGHT_REFERENCE_RANGES = ((180, 200), (810, 835))
MIN_INWARD_PX = 5.0  # 07・08の仮のしきい値
MIN_ROWS = 3  # 07・08の仮の最小連続行数
```

各側の指定した点に最小二乗法で `x = slope * y + intercept` の直線を当てます。
06の確認画像は赤が実際の端、水色が基準線、緑が選んだ正常部分、黄色が計測範囲です。
偏差は**水平方向**の距離で、左は `実際の端 - 基準線`、右は `基準線 - 実際の端` です。
正なら内向き、負なら外向きです。板厚方向の深さや、基準線へ垂直な距離とは異なります。
06のCSVには元の端座標、基準線のx、左右の符号付き偏差、正常部分を示す0/1を保存します。

07・08では、左右別に「内向き偏差がしきい値以上の連続行」を1候補とします。
しきい値未満の行で候補を分け、`MIN_ROWS` 未満の区間は数えません。
現在の仮条件は5px以上・3行以上です。位置CSVにはL01・R01などのID、開始/終了y、最大偏差の位置、行数を保存します。
IDはその画像内の番号です。同じy付近でも、左右は別々の候補として数えます。
候補がない場合は位置CSVがヘッダーだけになり、個数CSVに左右・合計の0を保存します。
07・08は、選んだ評価範囲の全行で端を取得できなければ停止します。未観測区間を候補0個とは扱いません。

08は各候補の `max_inward_px` と `span_along_reference_px` を保存します。
影響範囲は候補の開始/終了yに対応する**基準線上の2点間の距離**で、
`sqrt((slope * (end_y - start_y))**2 + (end_y - start_y)**2)` です。
垂直方向の範囲 `span_y_px = end_y - start_y` も保存します。15行の候補は14区間なので、垂直な基準線なら14pxです。
しきい値未満の部分は含めません。評価範囲の境界に触れる候補は `touches_boundary = 1` とし、途中までの値として確認します。
画像の各候補には「ID: 最大偏差px / 影響範囲px」を重ねます。

`08_candidate_summary.csv` は左・右・合計の3行で、候補数・最大偏差・影響範囲合計・境界に触れる候補数を保存します。
合計行の最大偏差は左右の最大値です。候補数と影響範囲は左右を足します。
計測範囲・しきい値・連続行数・正常部分の指定も、比較に必要な条件としてCSVに含めます。
