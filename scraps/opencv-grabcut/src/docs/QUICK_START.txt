6本のスクリプト　簡潔な利用ガイド
2026-10-23時点のsrc内のコードを対象とします。

準備と実行順

Python 3.14以降とuvが使える環境で、PowerShellを開きます。
以下のコマンドで題材フォルダへ移動し、初回は依存関係を準備します。

  cd "C:\Users\TkymHrt\dev\code-scraps\scraps\opencv-grabcut"
  uv sync

以降のコマンドも、このフォルダから実行します。
入出力用フォルダがなければ作成します。記載のパスは、このフォルダ基準です。
別の端末へ移す場合は、src内の共通設定とutilsも一緒にコピーします。

初回の順序：板生成 → 印刷・撮影 → 校正 → 画像補正 → 計測 → 作図
有効な板と校正係数がある場合は、画像補正から始められます。
画像補正の2本は、撮影方法に合わせてどちらか一方を使います。

共通設定はsrc/workflow_settings.pyです。
板のマス数・寸法を印刷物と一致させ、撮影モード・画角・解像度は校正時と合わせます。
MM_PER_PXは補正画像の倍率です。現在は0.25mm/pxで、変更したら補正画像も作り直します。
RECTIFY_ROIは補正で残す範囲です。現在は中央の幅50%で、必要なら調整します。
同名の補正PNGは上書きされるため、残したい結果は先に別フォルダへ保管します。


1. 00_1_generate_charuco_board.py：印刷用の板を作る

  uv run src/00_1_generate_charuco_board.py

出力：src/output/charuco_board.png
現在の板本体は210×150mm、1マス30mmです。余白込みの印刷寸法は230×170mmです。
印刷後に1マスと縦横の寸法を実測し、平らで硬い板へ貼ります。
板の仕様を変える場合は、workflow_settings.pyの板設定も合わせます。


2. 00_2_calibrate_camera.py：カメラを校正する

同じ撮影モード・画角・解像度で、板の位置や傾きを変えた複数の写真を用意します。
保存先：src/input/camera_calibration/ の直下

  uv run src/00_2_calibrate_camera.py

src/output/camera_detection/ の検出確認画像と、ターミナルの使用・除外結果を確認します。
表示されたCALIBRATION_SIZE、CAMERA_MATRIX、DIST_COEFFSの3設定を、
次に使う画像補正スクリプトの冒頭へ貼り付けます。自動転記はされません。
2本の補正スクリプトを使い分ける場合は、それぞれに設定します。


3. 01_rectify_images.py：各画像に板が写っている場合の補正

板付きの計測画像をsrc/input/の直下へ置きます。
寸法補正の基準にする板は、計測対象と同じ平面（高さ・傾き）に置きます。
冒頭の3設定に、手順2の校正結果が入っていることを確認します。

  uv run src/01_rectify_images.py

出力：src/output/rectified/ 内の、入力画像と同名のPNG
補正後の画像に、測りたい範囲と左右のエッジが残っていることを確認します。


4. 01_rectify_frames_from_reference.py：固定カメラで基準画像を共有する補正

手順3の代わりに使う方式です。各フレームに板がなくても補正できます。
板付き基準画像：src/input/video_reference/reference.png
処理する画像：src/input/video_frames/ の直下
基準画像と対象画像で、カメラ位置・向き・撮影モード・画角・解像度・計測面を固定します。
冒頭の3設定に校正結果を貼り、必要なら基準画像・入力先の設定も変更します。

  uv run src/01_rectify_frames_from_reference.py

出力：src/output/rectified_frames/ 内の補正PNG
基準画像の補正結果は、その中のreferenceフォルダに保存されます。


5. 02_measure_edge_lengths_gui.py：側辺を計測する

  uv run src/02_measure_edge_lengths_gui.py

操作順：
  1）「補正画像を読み込む」で、手順3または4の補正PNGを選ぶ。
  2）「多角形」「前景候補（橙）」を選び、計測区間の両端と左右側辺を余裕を含めて囲む。
      3点以上クリックし、「多角形を確定」を押す。
  3）必要なら「確実な前景（緑）」「確実な背景（青）」も追加し、それぞれ確定する。
  4）「基準区間長 (mm)」へ100などを入力し、「区間の中心」で測定位置をクリックする。
  5）「試料抽出・軸を自動推定」を押し、軸と上下の断面を確認する。
      方向が合わなければ「手動軸2点」で長手方向の2点を指定する。
  6）「長さを計測」を押し、「元画像」「計測結果」を切り替えて境界線を確認する。
  7）「CSV・画像2枚を保存」で、未使用の名前を付けて保存する。

試料の長手はおおむね画像の縦方向にそろえます。画像左がDR、右がOPです。
基準画像方式の出力を使う場合は、画像選択画面でrectified_framesフォルダへ移動します。
名前.csv、名前_initial.png、名前.pngの3ファイルが保存されます。
同名ファイルは確認なしで上書きされるため、区間・パスごとに別名にします。
マスク変更後は抽出からやり直し、中心や区間長を変えた場合も計測し直します。


6. 04_plot_pass_metrics.py：パス別の比較図を作る

冒頭のMEASUREMENTSを、実際に保存したCSVの一覧へ書き換えます。
1行は「実験回、パス番号、区間ID、CSV名」の順です。既存のリスト内の行を編集します。

  ("run01", 0, "a", "output/run01_pass00_a.csv"),
  ("run01", 2, "a", "output/run01_pass02_a.csv"),
  ("run01", 4, "a", "output/run01_pass04_a.csv"),

CSVの相対パスはsrc基準です。上の例ではsrc/output/内のCSVを指定しています。
現行02の計測CSVを使い、実験回・区間IDの組ごとにパス0のCSVを含めます。
パス番号は0以上の偶数整数です。同じCSVや同じ実験回・区間・パスを重複指定しません。
全CSVで基準区間長・倍率・評価間隔・平滑化幅をそろえます。
保存先を変える場合はGRAPH_DIRECTORYを編集します。

  uv run src/04_plot_pass_metrics.py

既定の出力先：src/output/pass_graphs/
  excess.png                 各区間の超過率
  change_from_initial.png    同じ区間・同じ側のパス0との差
  dr_op_difference.png       DR－OPの差。負ならOP側の超過率が大きい

現行版は区間ごとの線を描き、平均・標準偏差は自動集計しません。
既存の同名PNGは上書きされるため、前の結果を残す場合は出力先を変えます。


利用時に押さえること

人が画像・マスク・区間を指定して結果を確認し、計算と記録・作図をプログラムで行います。
超過率は側辺形状の指標であり、クラックの本数・深さや材料の伸び率を直接表しません。
反射などで境界が判断できない画像は、指定を増やせば必ず測れるものではありません。
エラー時は表示された画像名・理由を確認し、設定や指定を直して再実行します。
