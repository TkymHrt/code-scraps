# GoProでの撮影と、実画像を試す手順

作成日：2026-10-13。
GoPro（機種未定）で静止画と動画を撮影し、上からの照明1灯に日差しが混ざり、部分的な影が出る条件を想定します。
2026-10-15更新：魚眼レンズを前提とし、校正とレンズ歪み補正にはOpenCVの魚眼モデルを使います。
現在は床置きの局所写真を補正し、計測GUIで指定範囲の左右側辺長を測るPoCを進めます。
実測長と100mm換算を比較し、確認画像とグラフを見比べます。同じ材料区間の追跡・厚さの入力は必須にしません。
実行順は [現行の5工程](submissions/README.md) を参照してください。
内部の細い割れの個数・経路長や、動画全体の自動処理は現在の提出版の機能に含まれません。

以下の背景・角度・撮影枚数は、今回の初回比較の提案です。精度を保証する規格値ではありません。
最初から全条件を組み合わせず、**同じ試料で1条件ずつ変え、撮影直後に画像を確認する**進め方にします。

## 最初の撮影で揃えるもの

優先するのは、計測する区間の左右両側辺と背景の境目を人が読める局所写真です。試料全体が1枚に入る必要はありません。
上下端面が写る場合は、計測するときに開始y・終了yで除きます。側辺が画面外へ切れた写真は、この両側辺の計測には使いません。

| 優先度 | 撮っておくもの | 目的 |
| --- | --- | --- |
| 必須 | 床置き・単色のつや消し背景・できるだけ真上からの局所写真 | 初期指定と抽出方法を確認する基準画像 |
| 必須 | 試料もカメラも動かさず、同じ条件で3枚 | 撮影だけでマスクや数値がどれほど変わるかを確認する |
| 必須 | 同じ試料・構図で、日差しの影がない状態と、影が端を横切る状態 | 照明変化で端線やマスクが変わる箇所を確認する |
| 優先 | 背景材を敷かない実際の床、停止中のローラー上 | 基準条件から現場条件へ移したときの失敗を知る |
| 優先 | カメラを固定したまま、試料を置き直した写真3枚 | 位置・向きのずれと設定の使い回しへの影響を確認する |
| 優先 | 背景だけの写真と、撮影配置が分かる引きの写真 | 影・床模様・ローラー反射の説明に使う |
| 余裕があれば | 同じ構図の短い動画、左右の注目箇所の近接写真 | フレームの変動と細い割れの見え方を別々に確認する |
| 将来の比較用 | 同じ試料の圧延前後の写真、基準寸法が分かる写真 | パス間比較・mm換算のための入力を残す |

「割れが目立つ試料」だけでなく、左右端が比較的滑らかな試料も1例あると、反射や影を欠陥と見間違えていないか確認しやすくなります。
撮影前後で試料を削る・端を切り直すなどの形状変更をすると比較条件が変わるため、行った場合は記録します。

## 床と背景をどう選ぶか

最初は床の種類そのものより、**試料と色・明るさが違い、模様と光沢が少ない背景**を選びます。
明るい金属なら暗いつや消しの背景から試し、黒い酸化部分が背景と混ざる場合は中間色や明るい背景も比較します。
黒が常に最適とは限りません。

| 背景の候補 | 最初に試す位置づけ | 確認すること |
| --- | --- | --- |
| 無地の暗色・つや消しの板やマット | 基準候補 | 黒い試料部分が消えないか、材のしわや段差が影を作らないか |
| 無地の中間灰色・つや消し背景 | 暗色背景との比較 | 銀色の試料と明るさが近すぎないか |
| 無地の明るい背景 | 試料が暗い場合の比較 | 背景も試料も白く飽和して境目が消えないか |
| 平滑な塗装床・樹脂床 | 現場に近い比較 | 光沢、塗装の剥がれ、継ぎ目、油の反射 |
| コンクリート床 | 実際の床の適用確認 | 粒・ひび・汚れと試料の灰色が混ざらないか |
| 縞鋼板、錆・模様・油のある床 | 難しい条件として後で試す | 背景の凹凸や反射が試料につながらないか |

背景は試料の周囲にも十分に見える大きさにします。試料の端が背景板の端・継ぎ目・床の線に重ならないようにします。
温度や現場条件に適した背景材だけを使い、試料を撮影用に無理に押しつぶして形を変えないようにします。

## 位置・角度・高さ

基準写真は、**カメラの光軸を試料面にできるだけ垂直にし、保存した画像では試料の長手方向を縦にする**構図です。
三脚や固定具で、カメラの位置・高さ・向きを保持します。撮影者やカメラ自身の影も確認します。

| 項目 | 基準の取り方 | 比較として残す例 |
| --- | --- | --- |
| 画面内の位置 | 中央に計測区間を置き、左右に背景を残す | 位置を少しずらした写真 |
| 長手方向 | 画像の縦方向に合わせる | 面内で5〜10°程度傾けた写真を、設定の耐性確認用に1組 |
| カメラの傾き | 真上に近い位置から撮る | 真上から約10°、約20°傾けた写真を撮れる範囲で比較 |
| カメラの高さ | 計測区間と板が入り、左右端が十分な画素数で写る高さに固定 | 少し高い位置を1組。倍率が違うためpx値を直比較しない |
| 試料の置き方 | 上下面・圧延方向・左右の呼び方を統一 | 置き直し。裏返した写真は別条件として扱う |

斜めの写真は「この角度でも抽出できるか」を調べるために残します。補正前の画像を、真上の写真と同じ寸法に見えるとは扱いません。
魚眼レンズでも距離によって見かけの倍率が変わり、試料の反りやローラー上での高さの違いも影響します。
このため、同じ背景だけでなく撮影位置と試料面の高さも揃える方針です。
[Edmund Optics：遠近と倍率の変化](https://www.edmundoptics.com/knowledge-center/application-notes/imaging/advantages-of-telecentricity/)

GoProの広角で全体を入れても、細い割れが十分な画素数になるとは限りません。
例えば横500mmの視野が4000pxに写る場合、約0.125mm/pxで、幅0.1mmは約0.8pxです。
薄い線の存在が見える場合でも、その幅や形を安定に測る情報としては不足します。
全体写真と注目部の近接写真を分け、近接側でも100%表示でピントと端の明瞭さを確認します。

実寸のための定規や基準物は、可能なら**試料の計測面と同じ高さ**に置きます。
床上の定規と、厚み・反りのある試料上面では高さが違う場合があります。
左右端を隠さず、GrabCutの前景候補に定規やラベルが入らない位置に置きます。
画像ごとにmm換算する場合は、撮影画像に基準物も写しておきます。
ChArUco方式は、[現行の5工程](submissions/README.md) に従います。板生成とカメラ係数算出を一度行い、係数を `rectify_image.py` へコピペします。
撮影ごとは板を計測面と同じ高さ・同じ平面へ置きます。板の写真内の向きは任意です。
画像補正は写真内の向きを保つため、試料の長手は撮影時に画像の縦方向へ揃えます。
`rectify_image.py` は歪み・遠近を補正し、一定のmm/pxへ揃えたPNGを保存します。
カメラ校正時は `output/camera_detection/` の確認PNGで、マーカー枠・角のID・読取点数を確認します。
画像補正では計測用の補正PNGだけを保存します。エラーで止まったら元写真とエラーを見て入力を直し、前の出力を退避して再実行します。
計測GUIにも同じmm/pxを設定し、補正PNGの矩形・計測区間を指定して長さCSVと確認PNGを保存します。板と補正外の黒い余白は前景へ含めません。
局所比較GUIへ長さCSVを追加し、実測長と100mm換算を比較します。区間長を揃える場合は計測GUIのmm表示を目安にします。
実カメラの精度は未確認です。平面補正は試料の反りや板との高さの違いを補正するものではありません。
厚さと理想長を使う従来の比較を選ぶ場合は、圧延前の区間長・厚さと、各回の厚さを記録し、印などで同じ材料区間を追います。
この別案の理想長は幅一定・体積一定で求めます。どちらの比較でも、画像間のy座標を一致させる必要はありません。

## 上からの1灯と日差しをどう扱うか

今回の基準は、上からの1灯を使い、可能なら日差しの強い影が入らない場所・時間帯です。
一方、実運用で影が避けられないなら、その条件も同じ試料で撮影します。
「影なし」と「一部だけ影」の写真を別条件として残し、同じ状態の試料で見え方を比較します。

| 状態 | 撮影時に見ること | 次に試すこと |
| --- | --- | --- |
| 上からの照明が試料表面に映り込む | 白い反射帯で端や割れが消えていないか | 移動できれば照明を少しずらす。可能な設備なら拡散光との比較 |
| 試料全体が日陰、照明は同じ | 暗い側でも左右端と細部が見えるか | 露出を確認し、明るい条件の写真も別に残す |
| 片側だけ日陰 | 影側の端が背景に溶けていないか | 影のかかり方を記録し、影のない同じ構図と比べる |
| 影の境目が試料を横切る | 影の境目を切欠き・割れとして拾わないか | 影の位置が変わる短い動画も残す |
| 明るい側が白く飽和、暗い側が潰れる | 明暗どちらかの細部が失われているか | 遮光可能なら日差しを抑える。片側だけに合わせた露出で解決したと判断しない |

反射を抑えた均一な拡散光は外形確認の候補です。一方、低い角度からの光は傷や凹凸を強調できますが、影や模様も増えるため、外形用の写真とは別に比較します。
偏光を試せる場合も、金属面では効果が限定されることがあり、割れの見え方も含めて確認します。
[Basler：拡散光と偏光の特徴](https://www.baslerweb.com/en/learning/illumination/)、[Edmund Optics：低角度照明と表面の特徴](https://www.edmundoptics.com/knowledge-center/application-notes/illumination/darkfield-illumination-with-ring-lights-for-machine-vision/)

照明を増設できない場合も、同じ1灯での試料位置・撮影時刻・日差しの有無の比較はできます。
人工照明と日差しが混ざる場合、固定したWBだけでは場所ごとの色や明るさの差は消えません。
影を避けた基準写真を確保し、混在光の写真は別条件として残します。
カメラを傾けて反射を逃がした写真は、寸法用の基準写真と区別します。
原画像で読めない端を、マスクの指定だけで正しい境界にできたとは扱いません。

## GoProの設定で揃えるもの

機種とモードが決まってから対応する設定を確認します。以下は対応している場合の試験方針です。
静止画と動画で設定が別になっている場合があるので、両方を確認してください。

| 項目 | 基準の候補・注意 |
| --- | --- |
| 画角・デジタルレンズ | 魚眼の歪みが残るWideなどを基準候補にし、その設定で校正する。Linearなどの補正済み画角とは混在させず、画角を撮影途中で変えない |
| デジタルズーム・自動フレーミング | 基準ではズームを固定し、構図が自動で変わる機能を避ける |
| 動画の手ぶれ補正・水平維持 | 固定撮影ではOFFを基準候補にする。ONも使う必要があれば別条件として比較する |
| 静止画の処理 | 選べる場合はStandardを基準候補にし、SuperPhoto/HDRは別条件として比較する |
| ホワイトバランス | 同じ照明の比較では利用できる固定値を使う。Autoしか使えない場合はそのまま記録する |
| 露出・ISO | 明部の細部が残る露出を選び、利用できる露出固定やISO範囲を確認する。通常静止画でシャッターを固定できるとは限らない |
| シャープネス・色設定 | 同じモード内で揃える。途中で強調を変えて端の細かな凹凸を比較しない |
| 解像度・縦横比 | 静止画は元の解像度、動画は使える高解像度を基準に固定。写真と動画が同じ画角・倍率とは仮定しない |

GoPro公式では、デジタルレンズにより画角や魚眼の見え方が変わり、電子手ぶれ補正は画面のクロップを伴うと説明されています。
魚眼の歪みが残る撮影モードを固定して校正し、補正後の基準物の寸法を確認します。Linearなどの補正済み画角へ変えた画像に、この係数を流用しません。
[GoPro：デジタルレンズの例（HERO13）](https://community.gopro.com/s/article/HERO13-Black-How-To-Use-Easy-Controls?language=en_US)、[GoPro：HyperSmoothの仕組み](https://gopro.com/en/us/news/hero7-black-hypersmooth-technology)

露出・WB・ISO・写真の出力設定の対応や併用条件は機種によります。
例えばHERO10の説明ではSuperPhotoは場面に応じた処理を行い、Exposure Controlなどと併用できない条件もあります。
ここでは単純な設定の写真を比較の基準にする提案です。機種未定のまま同じ設定画面があるとは仮定しません。
[GoPro：HERO10公式マニュアル](https://gopro.com/content/dam/help/hero10-black/manuals/HERO10Black_UM_ENG_REVB.pdf)

広角で直線が曲がる場合は、同じモードで格子・既知の直線を写した画像も残します。
提出版はGUIなしで魚眼モデルのカメラ校正を行い、固定した4つの歪み係数とChArUco板でレンズ歪み・平面の遠近を補正します。通常モデルの係数は使えないため、撮影写真から求め直します。固定した画角・モード・解像度で、板を中央と上下左右の周辺へ移し、位置・傾き・距離を変えた写真を10枚以上撮ります。校正板に使わない既知寸法を中央・周辺で確認します。実カメラでの精度は未確認です。
[OpenCV：魚眼モデル](https://docs.opencv.org/5.0/main_modules/calib3d_fisheye.html)

## 静止画と動画を両方撮る

まず同じ固定構図で、静止画3枚と10〜20秒程度の停止状態の動画を1本残す案です。
動画は、対応するモードで4K・25/30fps程度を最初の候補にし、必要な解像度と照明条件を確認します。
これは設定を絞るための開始案で、どのGoProでも利用できる組合せを保証するものではありません。

動画では次も確認します。

- 前半・中盤・後半で構図や見かけの倍率が変わらないか。
- 止まっている試料でも、明るさ・色・端線が自動調整で変動しないか。
- 照明由来の横縞・ちらつきがないか。対応するAnti-Flicker等を照明環境に合わせて試す。
- 影が動く場合、同じ試料のマスクが影に合わせて変わらないか。
- 動く試料では端が流れないか。fpsを上げるだけで露光時間が十分短くなるとは仮定しない。

動体のぼけは露光時間中の移動に関係します。
例えば画像上で1000px/秒動く対象なら、露光時間1/1000秒で約1px移動します。実際の速度と明るさから選ぶ例です。
光量不足を高いISOだけで補うとノイズも増えるため、元画像の細部を確認します。
[Basler：露光時間と動体のぼけ・ゲイン](https://docs.baslerweb.com/optimizing-image-quality)

原動画をSDカードからそのまま保存します。解析用フレームは元動画から元解像度でPNG等へ書き出します。
再生画面のスクリーンショットや共有アプリで縮小された動画を、元解像度の入力の代わりにしないでください。
動画名・フレーム番号・抽出時の画像サイズを記録し、静止画とは別の画像IDにします。
まず安定した1フレームを補正と計測GUIで試し、その後に影のあるフレームや別時刻を同じ設定で試します。
フレームの書き出し・連続動画の解析は、現在の提出用の画像計測3本には組み込まれていません。

## 停止ローラー上で残したい条件

床で使える写真を確認してから、同じ試料を停止ローラー上で試します。
床から移すと背景・支持面・試料の高さが変わるため、床のpx長と直接比較するための撮影とは分けます。
カメラや照明を動かせない場合は、その固定位置のまま成立する範囲を確認します。

| 撮影するもの | 見たい問題 |
| --- | --- |
| 試料のないローラー | 金属の反射帯・溝・汚れがどの位置に見えるか |
| 試料全体と左右の露出したローラー | 反射帯が試料の端につながって抽出されないか |
| 同じ構図で影なし・影あり | 左右どちらかの端だけが消えないか |
| 可能なら少し配置を変えた同じ試料 | 試料の特徴と、支持面に固定された反射を区別できるか |
| 定位置の短い停止動画 | 露出変動・ちらつき・振動による変動 |
| 設備を含む引きの写真 | 遮蔽・撮影角度・照明配置と有効範囲の説明 |

背景指定は、試料の左右に実際に見えているローラーだけに置きます。
ローラーがある高さの行全体を背景にすると、その行の試料も背景へ固定してしまいます。
最大領域を選ぶ処理だけでは、試料につながった反射は取り除けません。
床と同じ初期指定をそのまま使うのではなく、計測GUIの初期指定から確認し直します。

定規・背景板などを設備へ置くのは現場で使用できる場合だけとし、稼働中のローラーへ撮影用の物を追加しません。
稼働中の動画は、停止状態の静止画・動画が確認できた後の別条件です。
ヒューム・遮蔽・ぼけで端が読めない区間は、欠陥なしや正常な寸法の区間として扱いません。

## 最初に実施する比較セット

まず下表の上から進め、F01を補正と計測GUIで確認してから撮影条件を増やします。
角度・高さ・背景・照明を同時に変えないことを優先します。

| ID例 | 条件 | 残す量の開始案 | 主な変更点 |
| --- | --- | --- | --- |
| F00 | 背景だけ・撮影配置 | 各背景で1枚ずつ | 背景と配置の記録 |
| F01 | つや消し単色背景・真上・影なし | 静止画3枚＋停止動画1本 | 基準 |
| F02 | F01から試料だけ置き直す | 静止画3枚 | 位置・向き |
| F03 | 実際の床、F01に近い照明・構図 | 静止画3枚 | 背景 |
| F04 | 採用した床条件で日差しの影あり | 静止画3枚＋短い動画 | 影 |
| F05 | 採用した床条件でカメラの傾き変更 | 各角度1〜3枚 | 角度。寸法比較とは分ける |
| R00 | 停止ローラーだけ・配置 | 各1枚 | ローラーと反射の記録 |
| R01 | 停止ローラー上、取れる最も正面の構図 | 静止画3枚＋停止動画1本 | 現場への適用 |
| R02 | R計測GUIの構図で影あり | 静止画3枚＋短い動画 | 現場の影 |

最初から大量に撮る必要はありません。F計測GUIで入力・マスク・端線が読めることを先に確認します。
条件を良くして成功した写真と、現場で避けられない難しい写真の両方を残すと、次に変える条件が分かります。

## 実画像1枚を試す手順

1. 元の写真・動画を保管し、解析用にはコピーを使う。撮影モード・解像度はカメラ校正と揃える。
2. 原画像でピント・白飛び・影・遮蔽を確認する。端が読めない場合は撮影条件を改善する。
3. 写真内の板を使い、`rectify_image.py` へ入力フォルダを指定して一括補正する。補正PNGは `output/rectified/` へ保存する。初回はカメラ係数を求めてコードへ貼る。
4. `initial_regions_gui.py` で補正PNGを読み、前景候補・確実な背景・確実な前景の矩形を描く。
5. 対応する材料区間の開始y・終了yを入力して計測する。赤い側辺と黄色の区間を確認する。
6. 撮影ごとの長さCSVと確認画像を保存する。誤った端を拾った値は採用せず、指定を調整して計測し直す。
7. 残りの写真も補正と計測GUIを行い、比較GUIへ複数CSV・初期区間長・初期厚さ・各回の厚さを入力する。

各スクリプトの実行順と設定は [submissions/README.md](submissions/README.md) にある。
画像ごとの入力・保存先と、補正・計測GUIのmm/pxの対応を運用で確認する。
結果を残したい場合は保存名や作業フォルダを分ける。同じ状態の撮り直しによる差を、圧延による差とは扱わない。
幅・凹み候補・旧rawマスク確認などは [退避した旧版](sandbox/previous_submissions/README.md) にある。

## 画像ごとの調整で見る症状

| 症状 | 先に確かめること | 試す対処 |
| --- | --- | --- |
| 試料の端が黒く消える | 青い背景指定が試料へ重なっていないか、前景候補が狭すぎないか | 指定を外へ移す・候補を広げて計測GUIで再計測 |
| 背景が白くつながる | 橙の候補が広すぎないか、灰色の背景候補も前景になっていないか | 試料の周囲を候補にし、実際の背景を上下左右で確定背景へ指定 |
| 割れの開口部が白く埋まる | 緑の前景指定で開口部を固定していないか | 緑を試料内部の小さな範囲へ移す。計測GUIの穴埋めとの違いも確認 |
| 影側だけ端が消える | 原画像で端を読めるか、露出や背景とのコントラストが不足していないか | 原画像が読めれば指定を調整。読めなければ照明・撮影を改善 |
| 明るい反射帯へ赤線が伸びる | 原画像と計測GUIの結果で、反射が試料につながっていないか | 反射部分を背景指定できるか確認し、困難なら照明・構図の別条件を試す |
| ローラーの1行だけ試料も消える | 背景矩形でその行全体を固定していないか | 試料の外側のローラーだけへ背景矩形を限定 |
| 計測GUIで別の物体が選ばれる | 板・ラベル・背景を試料として抽出していないか | それらを候補から外す。最大外側輪郭が試料とは限らない |
| 上下端面に沿って赤線が回る | 開始y・終了y が端面にかかっていないか | 両方の端面を避ける範囲へ変更し、計測GUIで再計測する |
| 同じ試料でも側辺長が変わる | 倍率・範囲・置き方・影・画角・補正・端の画素単位の揺れ | 同じ条件の反復画像で、撮影と指定の影響を分けて確認 |
| 内部の割れが長さに反映されない | 計測GUIは穴を埋めた外形の最外側を使う処理 | 注目部の写真を別に残す。外形の側辺長で内部割れを評価しない |

反復回数を増やすだけでは、間違って確定した前景・背景や白飛びした情報は直りません。
また、凹凸を消す平滑化を先に加えると、本物の切欠きまで消すことがあります。
まず撮影・初期指定・計測範囲の順で原因を調べます。

目視で試料だと確認できる影側が消える場合は、明るい部分と影側の部分それぞれに小さな確実な前景矩形を置く案も試せます。
確実な前景の矩形は複数指定できます。同様に背景も、明るい床と影になった床の両方を実際の背景だけで指定できます。
その際も、割れの開口部や判読できない場所を緑で固定しないよう計測GUIで確認します。

## 撮影後の判断と記録

最初の提出候補は、原画像で端が読め、計測GUIの固定指定が適切で、
計測結果の赤線と区間が意図した場所にある1画像です。
これは抽出と計測の動作確認で、実寸精度や割れ検出の正解率が確認できた段階とは分けます。

同じ状態の試料の3枚について、マスク・端線・長さの違いを見ます。
ばらつきが大きければ先に条件を揃え、撮り直しだけの変動を圧延による変化として扱わないようにします。
許容誤差は、実試料での変動と必要な欠陥サイズを見て決めます。ここでは任意の合格閾値を置きません。

作業フォルダの `note.md` などに、次の程度を人が記録すれば十分です。記録用のプログラムは追加しません。

```text
画像ID・試料ID・圧延パス・上下面／向き：
撮影日時、床／停止ローラー、背景材：
GoPro機種、静止画／動画、画角、解像度、fps：
手ぶれ補正・水平維持、写真の出力処理、WB・露出・ISOの設定：
カメラ位置・高さ・傾き、照明1灯の位置、日差し・影の状態：
動画ファイル名・フレーム番号（動画からの場合）：
初期指定・START_Y・END_Y（または実行したコピーの場所）：
補正・初期指定・計測で確認したこと、誤抽出・読めない箇所：
今回の結果を使える範囲、次に1つだけ変える条件：
```

圧延前後を比較する場合も、同じ試料・同じ撮影方式・対応する観測範囲を区別します。
画像の同じy座標や同じ高さの割合が、圧延後も材料の同じ位置を表すとは限りません。
個別の割れの追跡・位置合わせは後の工程です。
今回の撮影では、比較できる原画像と撮影条件を残すことを優先します。
