# 圧延実験から係数を求めるスクリプト：別要件

[本体の採用仕様](SYSTEM_PLAN.md)とは独立した `fit_mill_model.py` の要件を管理する。実装状況は[README](README.md#実装状況)を参照する。

## 1. 目的と対象データ

締め込み法は使わず、実圧延で得た荷重・ロール開き量・出側実測板厚から、採用モデルの係数を求める。まずロール幅程度の板幅を持つ板の実験を使う。ロール幅と実際の板幅は区別し、測った板幅を使う。

本体へ実測入力画面を追加せず、対応付け済みの実験CSVを単独スクリプトで読む。係数の手動確認後に本体の設定へ反映する。圧延中の自動学習・係数更新は行わない。

| 入力列の案 | 内容 |
| --- | --- |
| `side` | OP／DRのどちらのデータか |
| `width_mm` | 実験時の板幅 |
| `load` | 同じ側・測定位置・区間に対応する片側圧延荷重P |
| `gap_mm` | 該当側の圧下量計から求めた開き量S。未解釈の循環表示を直接入れない |
| `measured_thickness_mm` | 該当側・位置に対応する出側の実測板厚h |

P0、力の単位、基準幅b_ref、ロール・ゼロ基準条件は側ごとの入力条件として指定・記録する。1回の側別解析では同じP0・ロール・ゼロ基準のデータを使う。PとP0のSm計算には、各行の同じ板幅とkbを使う。ロガーCSV・OCR・実測の位置や時刻の対応付けは事前に行い、このスクリプトで自動照合しない。初期板厚だけでは出側板厚の実測を代用できない。

本体はOP／DR各1台の圧下量計と各側荷重を使うため、初期の係数特定も側ごとに対応付けたデータで行う。P0は該当側の値を使い、全体荷重と片側荷重を混ぜない。共通係数を使えるかは両側の実験データで確認する。実測がOP側だけなら、その値をDR側の実測として複製しない。計器2台でSの情報は増えるが、板幅補正に必要な複数幅データは引き続き必要になる。

## 2. 係数特定の前提

提示式から、荷重と伸びの関係は次のように整理できる。

```text
P = kb × (C1×Sm + C2×Sm^2/2)
```

任意の正数aについて、C1・C2をa倍、C3・C4・C5を1/a倍しても同じ荷重・伸びになる。そのためC1〜C5を無制約で一度に一意に決めることはできない。これは提示式からの代数的な帰結である。

そこで、広幅材で測った基準幅b_refを定め、`kb(b_ref) = 1` と正規化する。この条件のC1・C2を基準の剛性モデルとする。「ロール幅程度なら補正が厳密に1」と測定で確定したという意味ではなく、係数の尺度を定める定義とする。

一般にも、冗長なパラメータを持つ当てはめでは係数や共分散の解釈が不安定になる。[SciPy公式文書の過剰パラメータに関する説明](https://docs.scipy.org/doc/scipy/reference/generated/scipy.optimize.curve_fit.html)も参照する。今回の正規化条件は上記のモデル固有の式から決めたもので、SciPyの導入を要件にするものではない。

## 3. 段階1：基準幅のC1・C2

同じロール・ゼロ基準・P0・基準幅b_refで、異なる荷重条件のデータを複数用意する。実測から得られるのは `d = h - S = Sm(P) - Sm(P0)` であり、Sm(P)そのものではない。

同じkbをPとP0へ適用するモデルでは、基準幅で次の形にできる。

```text
d = h - S
P - P0 = A×d + B×d^2
C2 = 2×B
C1 = sqrt(A^2 - 4×B×P0)
```

A＞0・C1＞0の枝を使う。Sm(P0)を0として当てはめず、ゼロ設定荷重の影響を残す。この線形最小二乗を既存のNumPyで行い、荷重側の残差と、元の板厚式へ戻した誤差の両方を確認する。板厚・Sの測定誤差もあるため、最小二乗の係数をそのまま精度保証にはしない。

データの不足・荷重範囲の狭さ・行列の階数不足、平方根の条件不成立・非正剛性を検出したら、成功した係数として出力しない。`numpy.linalg.lstsq` では解とともに階数・特異値を確認できる。[NumPy公式仕様](https://numpy.org/doc/stable/reference/generated/numpy.linalg.lstsq.html)

## 4. 段階2：板幅補正のC3〜C5

1種類の基準幅だけでは、C3〜C5を個別に求められない。荷重条件を増やしても板幅方向の情報は増えない。

基準幅でC1・C2を求めた後、板幅ごとに段階1と同じ形の `P-P0 = A_b×d + B_b×d^2` を最小二乗で求める。基準のC1・C2と `A_b^2 = (kb×C1)^2 + 2×kb×C2×P0` の関係から、相対的なkbを計算する。

```text
D = C2×P0
kb_b = [sqrt(D^2 + C1^2×A_b^2) - D] / C1^2
```

A_b＞0を確認する。D≧0では桁落ちを避ける等価形 `A_b^2 / [sqrt(D^2 + C1^2×A_b^2) + D]` を使う。C2＝0ではkb_b＝A_b/C1となる。B_bの当てはめ値と予測板厚も整合性の評価に残す。

求めたkbを次の幅依存式へ当てはめる。

```text
x = b/1000
kb = C3 + C4×x + C5×x^2
kb(b_ref) = 1
```

`x_ref = b_ref/1000` として、次の2変数の線形最小二乗で正規化を保つ。

```text
kb_b - 1 = C4×(x-x_ref) + C5×(x^2-x_ref^2)
C3 = 1 - C4×x_ref - C5×x_ref^2
```

二次の幅依存を求めるには、基準幅を含む少なくとも3種類の異なる板幅が必要になる。これは数学的な最低条件で、実用上十分な点数・精度を保証するものではない。各幅でも荷重条件を振り、幅と荷重の影響を区別できるデータを使う。

基準幅しかない段階ではC1・C2と基準幅限定の結果を出し、C3〜C5を求めたことにはしない。板幅補正を未特定のまま、任意の板幅へ使える本体設定を完成扱いにしない。

## 5. 出力と実装範囲

- 求まった係数と対象側、基準幅・正規化条件、単位・P0・荷重定義、有効な板幅・荷重範囲を出力する。
- 各入力点の予測板厚と実測との差を比較CSVへ出し、件数・偏り・最大絶対誤差を要約する。これは実験解析用で、本体の機能には加えない。
- 不足データ、計算不能、未特定の係数を明示し、見かけ上の5係数で埋めない。
- 入力CSVは書き換えず、使用した実験条件・結果を追えるようにする。
- 標準ライブラリと既存のNumPyで1目的1スクリプトにする。GUI・DB・締め込み実験用の操作機能を追加しない。

側・荷重・S・実測位置の対応を揃えたデータを使う。提示式の尺度不定性、等価形、各段階の係数復元と正規化を合成データで確認し、実験データでの係数決定・モデル精度の確認と分ける。
