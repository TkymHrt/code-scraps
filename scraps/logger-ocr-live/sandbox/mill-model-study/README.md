# 過去圧延データによる板厚係数の試算

現行スクリプトでOP側の係数を求められた。ただし、現行の手順で幅補正を加えると、同じ基準曲線で幅補正を省いた場合に比べ、全点の板厚MAEは **0.043 → 0.085 mm**、1点ずつ外した評価では **0.050 → 0.092 mm** に悪化した。板厚誤差を直接最小化し、幅を一次式で表す案では、1点ずつ除外時 **0.046 mm**、1板幅ずつ除外時 **0.058 mm** だった。実用精度は別パスで確認する。

## 入力と比較条件

- 5052（H112）、公称入側板厚24 mm、板長300 mm、幅178・302・393・557 mm。基準幅は557 mm。ゼロ調整荷重はOP・DR各5 tfと仮定した。
- 表の和荷重はOP測定値の2倍なので、OPの入力Pは表の半分。DRは欠測。過去表のギャップと出側板厚がOPの対応する位置を表すかは記録から確認できないため、OP用の入力とみなした試算である。
- 36行中、荷重欠測11行を除く25行を使用した。393 mmのギャップ24.005／伸び−24.005の行は荷重・出側板厚とも欠測。伸びはコードと同じく出側板厚−ギャップで計算した。採用行では記載伸びと表示桁の範囲ですべて一致した。
- 旧剛性値133・139・141・164を和荷重基準の有効剛性（tf/mm）とみなし、旧剛性表による比較値を `h = gap + (2P−10)/K` とした。旧剛性値の算出元・手順は不明で、この資料との独立性は確認できない。
- 「幅補正なし」は現行の557 mmのC1・C2を全4幅に診断用に適用した値。誤差は予測−実測。MAEは平均絶対誤差。

## 幅補正で悪化した理由

現行は幅ごとに `P−P0 = A·d+B·d²`（`d=h−gap`）を当てはめ、主にゼロ荷重近傍の勾配Aの差を `kb` に換算する。最終式の二次項は各幅のBを自由には使わず、557 mmから求めたBに `kb` を掛けた値になる。

| 幅 mm | 幅ごとのA | 幅ごとのB | 現行の平滑化後kb | 最終モデルのB | 旧剛性比 K/164 |
|---|---:|---:|---:|---:|---:|
| 178 | 58.84 | 9.69 | 1.089 | 18.59 | 0.811 |
| 302 | 63.92 | 5.20 | 1.328 | 22.67 | 0.848 |
| 393 | 74.43 | −2.86 | 1.337 | 22.84 | 0.860 |
| 557 | 52.93 | 17.08 | 1.000 | 17.08 | 1.000 |

302・393 mmでは `kb` が伸びを抑え、同時に最終モデルのBが幅単独の当てはめより大きい。したがって荷重が上がるほど伸び不足が目立つ。5 tf近傍に観測がないためAは外挿した勾配で、少数点から推定するAとBは互いに影響しやすい。393 mm単独で得た負のBも、剛性の物理的性質として確定できない。旧剛性比は有効剛性から作った指標で、現行 `kb` と定義が異なる。比だけを現行C1・C2に入れた試算もMAE 0.077 mmで、幅補正なしの0.043 mmを上回った。

## 除外して再計算した結果

| モデル | 全点で当てはめ MAE | 1点ずつ除外 MAE | 1板幅ずつ除外 MAE |
|---|---:|---:|---:|
| 共通の線形剛性 | 0.073 | 0.082 | 0.093 |
| 線形荷重×幅一次のコンプライアンス | 0.046 | 0.056 | 0.056 |
| 現行・幅補正なし | 0.043 | 0.050 | 0.078 |
| 現行・幅補正あり | 0.085 | 0.092 | 0.219 |
| 板厚誤差で一括・幅一次 | 0.038 | 0.046 | 0.058 |
| 板厚誤差で一括・幅二次 | 0.036 | 0.046 | 0.066 |
| 伸びを荷重二次・幅一次の項で直接回帰 | 0.035 | 0.041 | 0.052 |

- 毎回、除外した点または幅を学習から外した。現行手順では557 mmを除くとき393 mmを基準とし、除外側の予測は適用範囲チェックを外して診断だけに用いた。178・557 mmの除外は幅の外挿、302・393 mmの除外は幅の内挿。荷重の外挿も含む。旧剛性表は固定かつ出所の独立性が不明なため、この表では除外評価と比較しない。
- 幅の内挿に当たる302・393 mmでも、現行の幅除外MAEは0.160、0.122 mm。板厚誤差で一括・幅一次では0.031、0.052 mm。178 mmの除外時に現行で最大0.856 mmまで悪化した。
- 一括当てはめは現行と同じ板厚式に正の `kb`、C1＞0、C2≧0の条件を置き、板厚残差の二乗和を全採用点で最小化した。幅除外時も係数の尺度を決めるため `kb(557)=1` を使った。幅二次でも現行の段階式より大幅に改善したため、幅の次数だけでは悪化を説明できない。幅一次の方が板幅を除外した評価で安定した。
- 比較用の直接回帰は `q=P−P0`、`x=(幅−557)/1000` として `d=a·q+b·q·x+c·q²/100`。このデータでは最小MAEだった。現行の板厚式とは異なるため、荷重や幅を外挿して使うには別の検証が要る。

## 感度と元データの確認箇所

| P0仮定 tf/側 | 旧剛性表 MAE | 現行・幅補正なし MAE | 現行・幅補正あり MAE |
|---:|---:|---:|---:|
| 0 | 0.074 | 0.061 | 0.107 |
| 3 | 0.048 | 0.051 | 0.094 |
| 5 | 0.044 | 0.043 | 0.085 |
| 7 | 0.060 | 0.037 | 0.086 |
| 10 | 0.093 | 0.046 | 0.139 |

- P0ごとに再推定した結果。試した範囲では幅補正ありの方が一貫して悪い。178 mmの現行 `kb` はP0を3、5、7 tfとするだけで1.246、1.089、0.884と変わる。この表から実際のP0は特定できない。
- 557 mmの31.8 tf（表の和荷重63.6 tf）は伸び0.604 mm。一方、28.75 tfでは0.370 mm。出側24.41 mmは公称入側24 mmを超えるため、実入側板厚、パスと位置の対応、荷重と開き量の読み取りを原票で確認したい。この点を学習から外すと、同じ残り24点で現行のMAEが0.082 → 0.055 mm、最大絶対誤差が0.457 → 0.349 mm。除外した点の誤差は−0.206 mmだった。点の採否で係数は動くが、この点の影響だけでは幅補正の悪化は解消しない。
- 掲載の旧二次式 `K = 0.0002·b² − 0.0785·b + 140.84`（`b` は板幅mm）を4幅へ代入すると、剛性のR²は0.9341。表の4剛性値に二次回帰し直すと、二次係数は0.0002141427、R²は0.98136となり、記載の0.9814と整合する。丸めた式での板厚MAEは0.048 mm、回帰し直した式では0.045 mm。ここでのR²は4点の剛性に対する値で、板厚予測の精度指標ではない。

## 追加検証

前回は全点への当てはめと、1点・1板幅ずつ外す評価を行った。今回は実測の空白に近い条件でどこまで予測できるかを見るため、荷重帯をまとめて外す評価と、4幅の共通荷重域だけで学習する評価を追加した。実機での追加測定は行っていない。

| 方法 | 全25点で当てはめ | 1点ずつ除外 | 1板幅ずつ除外 | 1荷重帯ずつ除外 | 共通荷重域だけで学習 |
|---|---:|---:|---:|---:|---:|
| 現行・幅補正なし | 0.043 | 0.050 | 0.078 | 0.046（18/25） | 算出不可（0/15） |
| 現行・幅補正あり | 0.085 | 0.092 | 0.219 | 0.080（10/25） | 算出不可（0/15） |
| 一括・幅一次 | 0.038 | 0.046 | 0.058 | 0.064（25/25） | 0.060（15/15） |
| 一括・幅一次・ロバスト | 0.034 | 0.040 | 0.054 | 0.043（25/25） | 0.037（15/15） |
| 伸びを荷重二次・幅一次の項で直接回帰 | 0.035 | 0.041 | 0.052 | 0.050（25/25） | 0.117（15/15） |

数値はMAE（mm）。括弧は予測できた件数／評価対象件数。MAEは予測できた点のみで求めた。欠測件数が異なる行のMAEをそのまま順位付けには使わない。

- **荷重帯をまとめて除外**。OP 25 tf以下、25 tf超～68 tf以下、68 tf超を順に学習から外した。25 tf以下を外した現行幅補正は178 mmで剛性の条件を満たさず、基準幅の3点のみ予測できた。68 tf超を外した場合は幅補正の剛性チェックを通らず、基準曲線でも高荷重7点を予測できなかった。幅一次の一括推定はその7点でMAE 0.119 mm、ロバスト版は0.060 mm。最大絶対誤差も0.283 → 0.152 mmだった。
- **共通荷重域で学習**。全幅の実測荷重範囲の交差である17.8～68 tfの10点で係数を求め、範囲外の15点を評価した。現行は基準幅の曲線が剛性の条件を満たさなかった。ロバスト版は15点のうち14点が±0.10 mm以内、最大は0.199 mm。前回の1点・1板幅除外でよかった直接回帰も、この条件では68 tf超の7点でMAE 0.215 mm、最大0.737 mmになった。どの抜き方でも一貫して良いかを確認する必要がある。
- **ロバスト版の違い**。板厚誤差の二乗和に代えて、誤差が大きな観測点の影響を抑える `soft_l1` を使用。尺度は探索用に0.05 mmとした。557 mm・31.8 tfを学習から外した場合、残る24点でのMAEは二乗和版が0.032 → 0.027 mm、ロバスト版が0.027 → 0.026 mm。ロバスト版はこの点の有無による変化が小さい。一方、1板幅除外時に最大0.328 mmの誤差があり、未知幅を使える精度までは確認できていない。

参考として、全点で求めたロバスト版のOP係数は C1=61.399697、C2=22.543814、C3=0.855143、C4=0.260066、C5=0。C3〜C5は現行と同じく幅の変数が板幅mm÷1000、557 mmで `kb=1` となる表記。C2≧0は候補に課した制約であり、全幅の物理的性質をこのデータから確定したものではない。

## 次の圧延試験

ロバスト版を検証候補とし、幅一次・二乗和版、幅補正なし、旧剛性表を同じパスで比較する。4幅で共通に測れるOP荷重を選び、可能なら20・35・50・65 tf付近などを別パスで反復する。68 tf超を使う場合は対象幅ごとにその荷重域も測る。OP／DRそれぞれのゼロ荷重・開き量・荷重・対応位置の実測板厚を記録し、同一パスの観測を学習と検証に分けない。荷重帯ごとのMAEに加え、最大絶対誤差と予測できた件数を確認する。

## 最初の板厚誤差比較だけを再表示する

最初の全点比較で使った旧剛性表、幅補正なし、現行の幅補正の3方式を取り出す。係数や予測板厚は、比較スクリプトが保存した値を使う。

1. [organize_errors.py](organize_errors.py) は冒頭の `POINTS_CSV` で [first-comparison-points.csv](first-comparison-points.csv) を読む。このCSVは過去25点の計算結果から必要な8列を取り出したもの。`TABLES_DIR` に、点別誤差の `errors.csv` と、全体・板幅別・荷重帯別・共通荷重域の件数や誤差を集計した `summary.csv` を作る。
2. [plot_errors.py](plot_errors.py) は同じ `TABLES_DIR` の2表を読み、幅別の荷重と誤差の散布図 `error_by_load.png` と、全体・幅別のMAE比較 `mae_by_width.png` を作る。

リポジトリルートから順に実行する。計算し直した結果を使う場合は `POINTS_CSV` を比較スクリプトが出力した `points.csv` に差し替える。再実行して別の結果を残すときは、`TABLES_DIR` を新しいフォルダに変える。

```powershell
$study = 'scraps/logger-ocr-live/sandbox/mill-model-study'
uv run --no-project --python 3.13 python "$study/organize_errors.py"
uv run --no-project --python 3.13 --with matplotlib==3.11.2 python "$study/plot_errors.py"
```

誤差は予測板厚−実測板厚。元の予測が空欄の点は比較表でも空欄で残し、集計の対象件数と予測できた件数を併記する。MAE図は全点を予測できた組だけ棒で表示する。比較は係数を求めたときと同じ測定点での誤差を表す。
