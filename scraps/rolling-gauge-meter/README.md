# NR-600からUSBで数値を読む

USB接続したNR-600の電圧チャンネルを、[read_logger.py](read_logger.py) ではコンソールに、[plot_logger.py](plot_logger.py) と [plot_logger_current.py](plot_logger_current.py) ではグラフに表示します。いずれもWAVE LOGGER PROを起動して収集を開始します。

## 準備

1. NR-600をWindows PCにUSBで接続し、製品版WAVE LOGGER PROとPythonを用意します。
2. WAVE LOGGER PROを手動で開き、対象の入力と収集周期を設定します。ノーマルモードの「収集設定 → サンプリング」で「連続収集」を選び、リピートとExcel転送を使わない設定で `.ucf` に保存します（NR-600マニュアル 6-39～6-40）。
3. 収集を止めて必要な保存を済ませ、前回の試行で開いた画面も含めてWAVE LOGGER PROをすべて終了します。

グラフ表示にはTkinterを使えるPythonが必要です。このフォルダで `pywin32` と `matplotlib` をインストールします。

```powershell
python -m pip install -r requirements.txt
```

## 設定と実行

使うスクリプトの先頭を現場に合わせて変更します。

| 設定 | 意味 |
|---|---|
| `SETTINGS_FILE` | 保存した `.ucf` の絶対パス |
| `DEVICE_ID` | NR-600本体のIDスイッチの値（0～3） |
| `CHANNELS` | 表示する `(入力ユニット番号, APIのCH番号)` の一覧。ユニットは1始まり、CHは0始まり |
| `READ_INTERVAL` | Pythonの表示間隔（秒、初期値は1.0）。装置の収集周期はWAVE LOGGER PROで設定 |
| `HISTORY_POINTS` | グラフに残す点数（初期値は60、グラフ用スクリプトのみ） |

初期設定はユニット1・2の電圧CH1～4（APIのCH番号0～3）、計8チャンネルです。実行前に `.ucf` のパス、本体ID、有効チャンネルを確認します。更新間隔と表示点数には正の値を指定します。構成が異なる場合は、WAVE LOGGER PROの設定とAutomationマニュアル p.8の対応表に合わせて `CHANNELS` を変更します。

WAVE LOGGER PROを手動で開き直さず、表示方法に合わせて1本を実行します。

### コンソール表示

```powershell
python read_logger.py
```

`Ctrl+C` で収集を停止します。

#### 表示の見方

```text
index=2, raw[U1/CH0]=12.5, raw[U2/CH1]=13.5
```

- `index` はPCに届いた最新サンプルの位置です。現在の保存区間の先頭を0とするため、`index=2` は3点目です。1行の値はすべて同じ位置から読みます。
- `raw[U1/CH0]` はユニット1、APIのCH番号0の測定値です。WAVE LOGGER PROでのスケーリング・平滑化・物理量変換前の値を表示し、その位置の値が無効なら `NA` と表示します。

表示するのは読出し時点の最新値なので、表示間隔によって `index` が飛んだり、同じ番号が続いたりします。連続収集の保存切替で `index` が先頭に戻ることがあります。1行の読出し前後で分割保存番号が変わった場合は、その行を表示せず次の読出しに進みます。

### グラフ表示

#### 波形の最新点を表示

```powershell
python plot_logger.py
```

PCに読み込まれた波形の最新位置から、全チャンネルを `GetData()` で読みます。同じサンプル位置の値を見比べるときに使います。

#### ユニットの現在値を表示

```powershell
python plot_logger_current.py
```

収集中に入力ユニットで更新される現在値を、チャンネルごとに `GetCurrentData()` で読みます。現在値の変化を追うときに使います。チャンネルを順に読むため、1回の更新に測定時刻の異なる値が含まれる場合があります（Automationマニュアル p.43～44）。

どちらのグラフも、既定では約1秒間隔で読み出し、8チャンネルの直近60点を表示します。横軸はPCで数えた経過秒、縦軸は換算前の測定値です。凡例の `U1 / CH1` はユニット1の電圧CH1で、値を取得できない点では線が途切れます。

グラフのウィンドウを閉じるか、実行したコンソールで `Ctrl+C` を押すと収集を停止します。設定が合わず実行に失敗した場合は、表示されたエラーを確認して修正し、再実行します。

WAVE LOGGER PRO側で収集が停止すると、各スクリプトは表示を終了します。読出しエラー時も停止を試みます。終了後はWAVE LOGGER PROの画面で停止を確認してから閉じます。

## 機器IDのエラー

機器IDの設定で `261`（`0x0105`）が出た場合は、準備手順どおりWAVE LOGGER PROをすべて閉じて再実行します。通常起動の初期設定では、収集していなくてもID 0が割り当てられます（NR-600マニュアル 6-18、Automationマニュアル p.14）。

## 確認状況

現場でUSB接続の1チャンネル取得に成功しています。コンソールの自動テスト10件が通り、両グラフとも模擬COMで8チャンネルの更新、欠損表示、ウィンドウを閉じたときと `Ctrl+C` 時の停止を確認しました。実機での複数チャンネルの連続表示とグラフ表示は未確認です。

